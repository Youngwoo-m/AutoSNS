# 크몽 서비스 등록 문구 — 학과·기관 홍보 자동화 패키지

> 크몽 등록 화면의 항목 순서대로 정리했습니다. 크몽 정책상 서비스 설명에 개인 연락처(전화·이메일·카톡 ID)와
> 외부 결제 안내는 넣으면 안 됩니다. 포트폴리오 링크(블로그·유튜브 주소)는 넣어도 됩니다.

## 카테고리
IT·프로그래밍 > 업무 자동화 (보조: 마케팅 > 블로그·SNS 관리)

## 서비스 제목 (30자 이내)
학과·기관 블로그·숏츠·SNS 매일 자동 발행 구축

## 한 줄 소개
글 쓰고 영상 만들고 올리는 일을, 매일 아침 알아서 돌아가는 시스템으로 만들어 드립니다.

## 서비스 설명

### 이런 곳에 맞습니다
- 홍보 담당자가 따로 없는 대학 학과, 연구실, 센터
- 블로그·유튜브를 만들어 놓고 몇 달째 멈춰 있는 기관
- 행사·공지·뉴스를 꾸준히 알리고 싶은 지자체 부서, 협회, 비영리 단체

### 실제로 운영 중인 시스템입니다
제가 직접 운영하는 블로그와 유튜브 채널은 아래 자동화로 매일 돌아갑니다.
- 블로그 2곳: 매일 새 글 자동 작성·발행(지금까지 100편 이상)
- 티스토리: 하루 2번 요약 글 자동 교차 발행
- 유튜브 숏츠: 블로그 글을 대본으로 바꿔 영상 제작·업로드, 재생목록 자동 분류
- 인스타그램·스레드·X: 같은 소식을 채널별 형식에 맞춰 동시 게시
- 주간·월간 성과 리포트 자동 발송
→ 정해진 시각에 돌아가는 작업이 22개입니다. 사람은 결과만 확인합니다.

포트폴리오: 재난안전과 GeoAI 블로그 https://geoaina.blogspot.com / 유튜브 https://www.youtube.com/@geoai-safety

### 만들어 드리는 것
1. 기관 주제에 맞춘 글 자동 작성(뉴스·공지·정보 글), 사람이 쓴 것처럼 읽히도록 문체·금지어 설정
2. 블로그 발행(Blogger·티스토리·네이버 중 선택)과 검색엔진 등록(Google·네이버·다음)
3. 글을 1분 숏츠로 바꿔 유튜브 업로드(제목·설명·태그·재생목록·썸네일 포함)
4. 인스타그램·스레드·X 동시 게시
5. 발행 결과 카카오톡 알림, 주간 리포트

### 진행 순서
1. 상담: 주제·채널·발행 빈도 정하기
2. 계정 연결: 기관 계정은 기관이 소유하고, 저는 자동 발행 권한만 받습니다
3. 시범 발행 1주: 매 글을 담당자가 확인한 뒤 공개
4. 자동 운영 전환 + 사용 설명서·인수인계

### 비용 안내
- 아래 가격은 구축비입니다.
- 글 작성 AI·AI 아나운서 등 외부 서비스 사용료는 실제 사용한 만큼 기관이 직접 결제합니다(보통 월 1~5만 원, 아나운서 영상을 쓰면 더 듭니다). 견적 때 미리 계산해 드립니다.
- 실행용 컴퓨터는 기관 PC나 저렴한 클라우드 서버 중 고를 수 있습니다.

## 자주 묻는 질문
**Q. AI가 쓴 글이라 검색에서 불리하지 않나요?**
A. 주제별 사실 확인 규칙, 금지 표현, 출처 표기를 넣어 사람이 읽기 좋은 글로 만듭니다. 처음 1주는 담당자가 확인한 뒤 공개합니다.

**Q. 계정 비밀번호를 넘겨야 하나요?**
A. 아닙니다. 블로그·유튜브는 공식 API 권한(언제든 취소 가능)으로 연결합니다.

**Q. 구축 후 멈추면 어떻게 하나요?**
A. 실패하면 카카오톡으로 알림이 갑니다. 월 관리를 신청하시면 제가 바로 고칩니다.

**Q. 학교·기관 내부 승인이 필요합니다.**
A. 견적서·작업 범위서·보안 안내 문서를 드립니다.
