진행 순서

  1. 상담주제·채널·발행 빈도를 정합니다
  2. 계정 연결계정은 기관 소유 그대로, 공식 API 권한만 받습니다
  3. 시범 발행 1주매 글을 담당자가 확인한 뒤 공개합니다
  4. 자동 운영 전환사용 설명서와 인수인계 문서를 드립니다

자주 묻는 질문

AI가 쓴 글이라 검색에서 불리하지 않나요?

주제별 사실 확인 규칙, 금지 표현, 출처 표기를 넣어 사람이 읽기 좋은 글로 만듭니다. 처음 1주는 담당자가 확인한 뒤 공개합니다.

계정 비밀번호를 넘겨야 하나요?

아닙니다. 블로그와 유튜브는 공식 API 권한으로 연결하며, 기관이 언제든 권한을 취소할 수 있습니다.

자동화가 멈추면 어떻게 하나요?

실패하면 카카오톡으로 바로 알림이 갑니다. 월 관리를 신청하시면 제가 고칩니다.

학교·기관 내부 승인이 필요합니다.

견적서, 작업 범위서, 개인정보·보안 안내 문서를 드립니다.
