# 글에 수식이 나올 때: 수식 이미지 + Manim 도식 GIF 넣기 (프롬프트)

글(블로거·티스토리·네이버)에 수식이 나오면 **① 수식은 LaTeX 로 정확히 써서 이미지로**, **② 개념은 Manim 도식 GIF 로** 보여준다.
이 문서는 글쓰기 세션·클로드 자동 작업에 그대로 붙여 쓰는 지시문이다. (2026-10-22 초안, 샘플로 검증 중)

## 지시문 (복사해서 쓴다)

```
이 글의 원고에 수식이 있으면 아래 순서로 처리한다. 수식이 없으면 아무것도 만들지 않는다.

1. 수식 찾기
   - 원고에서 계산식·공식(예: γd = γt / (1 + w/100))을 모두 골라 번호를 붙인다.
   - 기호의 뜻·단위·출처(법규·기준·교재)를 표로 정리한다. 출처가 없으면 만들지 말고 "확인 필요"로 표시한다.
   - 숫자 계산이 있으면 calc-verifier 에이전트로 먼저 검산한다.

2. 수식 쓰기 (LaTeX)
   - 모든 수식을 LaTeX 로 쓴다. 한 줄에 한 식, 기호는 원고와 똑같이.
   - 글에는 수식 이미지(Manim MathTex 로 그린 투명 PNG, 가로 1000px 이하)를 넣고, 같은 식을 alt 문구로도 적는다.
   - 본문 줄글 안의 짧은 기호(γd, w)는 이미지 대신 유니코드 글자로 쓴다.

3. Manim 도식 GIF (글당 1~2개, 가장 중요한 식만)
   - 식이 "왜 그렇게 되는지"가 도식으로 보이는 것만 만든다(예: 흙의 3상 도식 → 식 전개).
   - 장면은 6~10초, 1280×720, 15fps, 색 팔레트는 녹색 #1F4E3D · 짙은 녹색 #143528 · 모래색 #E8DCC2 · 강조 #FFD27A.
   - 한글은 Pretendard Bold, 식은 MathTex. 화면 안 글자는 짧게(제목 한 줄 + 라벨).
   - 사고·부상 같은 고통스러운 장면은 쓰지 않는다. 도식·그래프·단면도만.
   - 렌더: `math_gif/render.sh 장면.py 장면이름` (mp4 로 그린 뒤 팔레트 GIF 로 변환, 2MB 이하 점검). 샘플은 600px·10fps·32색에서 160KB. Manim 이 직접 만든 GIF 는 60MB 까지 커지므로 쓰지 않는다.

4. 글에 넣기
   - Blogger: GIF·PNG 를 공개 이미지 저장소(Youngwoo-m/geoai-assets)에 올리고 https 주소로 `<img>` 를 건다.
   - 티스토리: 파일 첨부(`data-ax-attach`)로 넣는다.
   - 모든 이미지에 alt 문구(식 또는 그림 설명)와 한 줄 캡션을 단다.

5. 확인
   - 발행 전 --dry 로 이미지가 보이는지, 식 기호가 원고와 같은지 눈으로 확인한 결과를 보고한다.
   - 출처 표기는 source-reviewer 로 검토한다.
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `math_gif/soil_phase.py` | 샘플 장면 `SoilPhase`(흙의 건조단위중량) — 새 장면은 이걸 복사해 쓴다 |
| `math_gif/render.sh` | 렌더 → GIF 변환 → 용량 점검 |
| `math_gif/samples/` | 샘플 GIF(160KB)·수식 PNG |

## 환경 (2026-10-22 확인)
- Manim 0.22(별도 venv), BasicTeX + `standalone`·`preview` 등 패키지, `dvisvgm`. 수식은 실제 LaTeX(`MathTex`)로 그려진다.
- 한글은 장면 안에서 `register_font`로 Pretendard Bold(assets/FONTS)를 불러 쓴다.
