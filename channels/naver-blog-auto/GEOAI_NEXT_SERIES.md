# GeoAI 다음 시리즈 — geoai 패키지 실습 (윈도우 검증용)

지금 시리즈(GeoAI 기초 67편)는 2026-10-22 무렵 끝난다. 다음 시리즈는
[opengeoai.org](https://opengeoai.org/) 의 `geoai` 파이썬 패키지와 QGIS 플러그인으로
"직접 해 보는" 실습을 다룬다. 실습 글은 따라 하다 막히면 안 되므로, 각 편은
**윈도우 PC 에서 실제로 돌려 본 뒤에** 쓴다.

작성 2026-09-27. 아래 버전·요구사항은 바뀔 수 있으니 실습 당일 다시 확인한다.

## 1. 이미 확인한 것 (윈도우에도 해당)

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| 패키지 이름 | `pip install geoai-py`. **`geoai` 는 PyPI 의 빈 껍데기(0.0.0.0)** — 글에서 반드시 짚는다 | PyPI 조회 |
| 최신 버전 | geoai-py 0.43.1 (torch 2.10 이상 요구) | PyPI 조회 |
| 만든 곳·라이선스 | Qiusheng Wu 주도, NASA·USGS 지원, **MIT 라이선스** | opengeoai.org |
| 건물 추출 모델 | `BuildingFootprintExtractor` 기본 모델은 `building_footprints_usa.pth` — **미국 항공사진(NAIP)으로 학습** | 패키지 소스 |
| 건물 추출 동작 | 샘플 NAIP 영상(2503×1126px, 0.6m)에서 건물 749개 추출, 직각 보정까지 끝까지 돎 | 맥에서 실행 |
| QGIS 플러그인 | 공식 플러그인 저장소에 있음. QGIS 3.28 이상, 파이썬 3.10 이상 | opengeoai.org/qgis_plugin |
| **윈도우 주의** | **QGIS 3.42.2 는 윈도우에서 프로젝트 저장이 실패** — 3.44 이상 권장 | 플러그인 문서 |
| 플러그인 기능 | DeepForest(나무), **OmniWaterMask(수역)**, Moondream(비전-언어), SamGeo(SAM), 의미 분할 학습·추론, Mask R-CNN | 플러그인 문서 |
| SAM 3 | **NVIDIA GPU(CUDA) 필수**, CPU 전용 PC 불가, Hugging Face 인증 필요 | 플러그인 문서 |
| 샘플 데이터 | `https://huggingface.co/datasets/giswqs/geospatial/resolve/main/naip_rgb_train.tif` | 패키지 소스 |

## 2. 맥에서만 생긴 문제 (윈도우는 해당 없음)

Intel Mac 은 torch 가 2.2.2 에서 멈춰 geoai 0.42 까지만 깔리고, 그대로 두면 NumPy 2·
transformers 와 충돌해 망가진다(`numpy<2`, `transformers<4.50` 로 우회). **윈도우는
최신 torch 를 받으므로 이 우회가 필요 없다.** 글에는 "Intel Mac 은 권하지 않는다"
정도로만 적는다.

## 3. 윈도우에서 확인할 것

실습 전에 PC 사양부터 적어 둔다 — 글에 "이 사양에서 이만큼 걸렸다"를 넣으면 독자에게
가장 쓸모 있다.

- [ ] PC 사양: CPU / RAM / GPU(NVIDIA 여부) / 윈도우 버전
- [ ] 파이썬 버전 (3.10 이상)
- [ ] `pip install geoai-py` 가 한 번에 되는지, 몇 분 걸리는지, 설치 크기
- [ ] `pip check` 에 충돌이 없는지
- [ ] GPU 가 있으면 `torch.cuda.is_available()` 이 True 인지
- [ ] QGIS 버전 (3.44 이상), 플러그인 설치와 의존성 설치가 되는지
- [ ] 아래 목차 각 편의 "검증" 항목

## 5. 화면 캡처를 글에 붙이는 법

실습하면서 찍은 캡처는 이미 있는 흐름을 그대로 쓴다.

1. 캡처를 `shots/<slug>/` 에 넣는다. 파일 이름 앞 번호가 단계 번호다(`02 새 프로젝트….png`).
2. 글이 나간 뒤 `./.venv/bin/python geoai_shots_apply.py <slug>` 로 붙을 자리를 미리 보고,
   `--go` 로 반영한다. 본문 글·제목·주소는 건드리지 않고 따라하기 칸만 고친다.

검증·캡처 때문에 기초 편보다 만드는 데 훨씬 오래 걸리므로, 시작 전에 검증을 충분히
