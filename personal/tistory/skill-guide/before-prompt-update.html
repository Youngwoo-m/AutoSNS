안전한국훈련 기본계획·실행계획·통합시나리오를 AI로 작성할 때는 자료의 출처와 문서 간 일관성이 중요합니다. 이 글은 safekorea-hwpx와 autoprompt v2.0.0의 다운로드, 환경별 설치, 문서 작성 요청 예시를 정리합니다. 확인일: 2026년 10월 8일.

1. 다운로드와 두 스킬의 역할

safekorea-hwpx 저장소에서 Code → Download ZIP을 선택하거나 아래 명령으로 내려받습니다. SKILL.md, references, assets, scripts를 함께 보존하세요.

git clone https://github.com/Youngwoo-m/safekorea-hwpx.git

safekorea-hwpx는 훈련문서의 구성, 매뉴얼 정합성, 목표·증빙, 비식별화 기준을 제공합니다. HWPX 패키지 편집과 실제 한컴 검증에는 별도 hwpx 스킬과 실행환경이 필요합니다. 저장소 README는 Codex용으로 설명하므로 다른 제품에서는 지침 활용부터 시험해야 합니다.

autoprompt는 코딩 에이전트의 작업 계획·실행·검증을 위한 도구입니다. 문서작성 앱 자체나 HWPX 변환기는 아닙니다. 사용자 지정 버전의 설치 명령은 다음과 같습니다.

npm install -g https://github.com/Spielewoy/autoprompt-skill/releases/download/v2.0.0/autoprompt-skill-2.0.0.tgz
autoprompt

Node.js 20+, Python 3.11+와 PyYAML, macOS/Linux의 Bash 4.3+가 필요합니다. 설치 프로그램에서 Codex 또는 Claude Code와 경로를 선택합니다. v2.0.0 배포 페이지에서 버전을 확인하세요.

2. ChatGPT: 자료 첨부와 스킬 선택

ChatGPT에는 터미널의 npm 명령을 입력해서 로컬 CLI를 설치할 수 없습니다. 가장 쉽게 시작하려면 내려받은 SKILL.md, 필요한 references 문서, 기관 매뉴얼·양식을 대화에 첨부합니다. 아래 요청은 첨부 지침을 활용하는 방식입니다.

첨부한 safekorea-hwpx 지침과 자료를 읽고 2026년 공공기관의 지진·화재 복합재난 토론훈련 기본계획 초안을 작성해 주세요. 위기관리 표준·위기대응 실무·현장조치 행동매뉴얼의 적용범위와 개정일을 표로 비교하고, 목적·기관별 역할·상황부여·평가·개선계획을 구성하세요. 기관명·일시·자원·승인 여부는 자료에 없으면 [확인 필요]로 표시하세요. 계획-실행계획-시나리오 정합성 표와 출처 목록을 함께 주세요. 이 예시는 가상 훈련이며 실제 성과를 만들지 마세요.

스킬 기능을 제공하는 ChatGPT 데스크톱에서는 사이드바 Skills에서 목록을 확인하고 @로 등록된 스킬을 선택합니다. 재사용 지침을 만들 때는 @skill-creator에 첨부 자료로 스킬을 구성해 달라고 요청할 수 있습니다. 웹·모바일의 플러그인 배포와 로컬 스킬은 방식이 다르므로, 이름만 입력했다고 설치된 것으로 판단하지 마세요. OpenAI 공식 안내를 기준으로 사용 환경을 확인하세요. autoprompt CLI는 이 브라우저 대화의 실행기로 등록하지 않습니다.

3. Codex: 설치 요청과 실제 호출

Codex에서는 다음 설치 요청을 입력합니다. 저장소 루트에 SKILL.md가 있는 이 스킬을 대상으로 지정하세요.

$skill-installer를 사용하여 https://github.com/Youngwoo-m/safekorea-hwpx 의 루트 스킬을 설치해 주세요.

설치 후 스킬 목록에서 safekorea-hwpx를 확인합니다. 수동 설치 시 현재 공식 문서는 프로젝트의 .agents/skills 또는 개인 ~/.agents/skills 아래 스킬 폴더를 안내합니다. 앱 버전에 따라 기존 경로도 사용하므로 설치기가 제시하는 경로와 실제 목록을 대조하세요.

$safekorea-hwpx를 사용해 첨부한 2026년 공공기관 지진훈련 계획과 승인 매뉴얼을 대조해 주세요. 기본계획·실행계획·통합시나리오의 불일치, 판단 근거, 수정안, 확인자료를 표로 작성하고 미확인 값은 [확인 필요]로 남겨 주세요.

autoprompt는 터미널에서 설치 확인 후 공식 launcher로 명시적으로 시작합니다. 아래 /absolute/project는 본인의 절대 작업폴더 경로로 바꿉니다.

autoprompt doctor codex --strict
autoprompt activate codex --target /absolute/project -- "safekorea-hwpx 지침을 읽고 훈련문서 자료목록 검사 도구와 출처 누락 체크리스트를 작성·검증해 주세요."

4. Claude: ZIP 업로드와 문서 요청

Claude에서는 코드 실행·파일 생성 기능을 활성화한 뒤 Customize → Skills → + → Create skill → Upload a skill로 ZIP을 올리고 켭니다. ZIP은 safekorea-hwpx 폴더 안에 SKILL.md와 필요한 하위 자료가 들어가도록 준비합니다. GitHub ZIP의 safekorea-hwpx-main 폴더 이름은 safekorea-hwpx로 정리해 다시 압축하는 편이 명확합니다. 조직의 권한에 따라 업로드 메뉴가 제한될 수 있습니다. Claude 공식 안내.

safekorea-hwpx 스킬의 문서 구성·근거 확인 지침을 적용해 주세요. 첨부한 2026년 학교시설 화재 매뉴얼과 빈 양식으로 토론훈련 실행계획 초안을 작성하고, 대피·구조·보고·안전관리의 담당기관과 증빙자료를 표로 연결해 주세요. 근거 없는 시간·인원은 [입력]으로 남겨 주세요.

이 요청은 문서 지침 적용 예시입니다. Codex 전용 호출 표기와 한컴 검증 단계가 Claude에서 그대로 작동하는지는 별도 확인해야 합니다. autoprompt CLI를 Claude 웹용 ZIP 스킬처럼 업로드하는 방법은 이 배포본의 설치 절차가 아닙니다.

5. Claude Code: 로컬 폴더와 launcher

다운로드한 스킬 전체 폴더를 개인 ~/.claude/skills/safekorea-hwpx/ 또는 프로젝트 .claude/skills/safekorea-hwpx/에 복사합니다. SKILL.md의 상대경로 자료를 함께 유지하고, Claude Code에서 목록을 확인한 뒤 다음과 같이 요청합니다. Claude Code 공식 문서.

/safekorea-hwpx 2026년 지자체 산불 토론훈련 자료를 검토해 주세요. 첨부 승인 매뉴얼과 계획·시나리오의 지휘·보고체계 불일치를 근거와 함께 정리하고, 확인되지 않은 기관 역할은 [확인 필요]로 표시해 주세요.

autoprompt 설치 프로그램에서 Claude Code를 선택한 뒤 터미널에서 실행합니다.

autoprompt doctor claude --strict
autoprompt activate claude --target /absolute/project -- "safekorea-hwpx 자료의 파일목록과 출처 검사 도구를 작성하고 검증해 주세요."

v2.0.0의 autoprompt는 일반 스킬 호출과 달리 공식 activate 명령으로 시작합니다. /autoprompt는 지원 호출로 안내하지 않습니다. 이번 Mac에서는 Codex 설치와 doctor의 정적 검사를 통과했으며, 실제 작업의 동적 사전검사와 Claude 환경 실행까지 확인한 것은 아닙니다.

6. 실무 적용 순서와 요약

① 적용 연도와 기관·재난유형 지정 → ② 현행 승인 매뉴얼과 양식 첨부 → ③ 기본계획부터 실행계획·시나리오로 확장 → ④ 역할·시간·자원·증빙 정합성 점검 → ⑤ 별도 HWPX 편집·한컴 검수 순으로 진행하세요. 과거 예시의 수치와 기관명은 실제 계획으로 복사하지 않습니다.

문서 내용은 safekorea-hwpx 기준으로 작성하고, autoprompt는 지원되는 코딩 에이전트의 자료 검사·도구 제작에 연결합니다. 최종 HWPX 납품은 실제 열기와 렌더링 검수까지 마친 뒤 판단합니다.
