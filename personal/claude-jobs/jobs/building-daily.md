# 건축시공 하루 한 문제 (티스토리+개인 블로거)

(토목시공 지시문을 바탕으로 2026-10-27 새로 만듦. 실행 수단은 공통 규칙이 우선)

매일 한국시간 오전 9시에 건축시공기술사 ‘하루 한 문제’ 블로그 원고 1편을 작성한다. 작업 경로는 /Volumes/USB256/devAPP/AutoSNS/GeoAI_NA/building-engineer-writing/이며 작성기준.txt와 첫 일차 원고가 생기면 그 형식을 따른다(형식 견본은 토목시공 personal/civil-engineer-writing/01일차_흙의다짐). 사용자가 2026-10-27 건축시공기술사 추가를 지시했다(토목시공과 같은 방식). 원고·따라쓰기 PDF를 작성·검증한 뒤 티스토리와 개인 Blogger에 공개 발행한다. 입문 글이 없으면 첫 실행에서 `첫글_준비하기` 입문 글부터 만들고(문제 풀이용 PDF 없음), 이미 있으면 그 글과 작성된 일차를 확인하여 날짜·일차·주제 중복을 피하고 다음 미작성 일차부터 이어간다.

주제 선정은 기출분석_2022-2026/ 의 2022~2026년(제126~140회) Q-net 문제지 분석(회차목록.json, 전체문항.json, 키워드집계.json)을 근거로 한다. 이 분석 폴더가 아직 없으면 글을 쓰지 말고 `skipped`(사유: 기출분석 미준비)로 기록하고 보고한다 — 기출 번호를 추정해 쓰지 않는다. 기존 고정 10분야 순환보다 빈출 유형 우선 원칙을 우선 적용한다. 분석에서 확인된 빈출 분야의 미작성 핵심 유형을 검토하고, 개별 유형의 실제 출제 회차·교시·번호를 원문과 대조해 반복 출제가 많은 유형을 우선 선정한다. 대분류 키워드 합계를 개별 문제 빈도나 공식 출제 비중으로 바꾸어 주장하지 않는다. 그룹 간 중복 집계 한계를 밝히고 동일 유형의 불필요한 반복을 피한다. 주제 선정 근거와 관련 기출을 작성상태.json에 기록한다.

제목은 반드시 ‘[건축시공기술사]’로 시작한다. 문제 바로 위에 ‘시험 종목: 건축시공기술사 / 과목(학습 분류): 토공·다짐, 콘크리트공 등 해당 분야 / 유형: 단답형 또는 논술형 / 관련 기출: 연도·회차·교시·번호’를 표시한다. 학습용 과목 분류를 공식 시험 과목명이라고 설명하지 않는다. 기출 원문·기출 변형·창작 연습문제를 명확히 구분한다.

전문 필자가 설명하는 자연스러운 ~이다/~한다체로 쓰며 허위 자격·경력·현장 체험을 만들지 않는다. 문제·답안 목차·답안예시·필요한 도식/표/검산·현장 적용 조건·자가점검·공식 출처·태그를 문제에 맞게 구성한다. Q-net 실제 답안지에 옅은 회색 #B8B8B8 글씨의 따라쓰기 PDF를 만들고 전 페이지 렌더 검토한다. 법령·KCS/KDS/KS 적용판과 수치·단위·가정을 확인한다.

건축시공 전용 질문 페이지(https://geoai-na.netlify.app/building-questions/)는 Netlify 배포와 접수 양식(building-engineer-questions) 확인이 작성기준.txt 에 기록된 경우에만 ‘함께 푸는 [건축시공기술사] 답안지 요청’ 안내를 블로그 상단에 넣는다. 아직 구현 전이면 임의로 주소를 만들어 공개 원고에 넣거나 측량 전용 링크를 건축시공용이라고 표시하지 않는다.

초안·편집은 클로드가 하고 계산은 calc-verifier, 출처는 source-reviewer 로 검토한다(공통 규칙). API 결제·새 계정·영상 제작·카카오톡 전송은 이 예약의 범위에 포함하지 않는다. HTML 원고·미리보기·PDF·작성상태와 양쪽 공개 URL을 저장하고, 발행 후 실제 공개 본문·그림·PDF를 검증하여 링크를 보고한다. 실패 시 자료와 상태를 보존하고 새 실패 또는 필요한 조치만 알린다.

친구 요청 접수·작성·별도 공개 발행은 별도 예약 ‘건축시공기술사 친구 요청 · 매일 밤 11시 발행’에서 매일 한국시간 23:00에 처리한다. 이 오전 9시 예약은 정기 원고 1편의 작성·검증·공개 발행만 처리하고 친구 요청을 중복 처리하지 않는다. 건축시공 공개 답안 목록은 queue.py --exam building add-post로 등록하며, 미발행 원고·입문 안내는 목록에 넣지 않는다.
카테고리는 ‘건축시공기술사’(티스토리 카테고리 ID 는 만든 뒤 작성기준.txt 에 적는다)를 사용한다.
상단 제목2 링크는 ‘함께 푸는 [건축시공기술사] 답안지 요청’으로 하고 https://geoai-na.netlify.app/building-questions/ 로 연결한다. 바로 아래에는 ‘문제를 요청하시면 접수 순서에 따라 매일 밤 11시에 요청을 확인하고, 정답예시와 따라쓰기 PDF를 작성해 블로그에 올립니다.’를 표시한다.

건축시공기술사 글은 토목시공과 같이 티스토리와 개인 Blogger(geoaina.blogspot.com, 학과 Blogger 에는 올리지 않음)에 함께 공개한다. Blogger 의 그림·PDF 는 site/geoai-site/building-questions/materials/ 의 검증된 https 주소로 연결한다. 제목·일차 중복을 먼저 확인하고, 두 블로그 URL·검증 상태를 따로 기록한다. 이 예약은 원고·PDF 검증 뒤 두 곳 공개 발행까지 수행한다.


공개 전 확인(2026-10-27): 건축시공 전용 개인 티스토리 카테고리·Netlify 접수 양식·기출분석이 준비되기 전에는 공개 발행하지 않는다. 준비 상태는 작성기준.txt 맨 아래 "준비 상태"에 사용자 확인으로 적힌 것만 믿는다.
