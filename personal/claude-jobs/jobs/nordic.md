# 노르딕워킹 아침 글

(Codex 자동화 'automation-3' 에서 2026-10-18 옮김. 아래는 사용자 지시 원문 그대로 — 실행 수단은 공통 규칙이 우선)

매일 한국 시간(Asia/Seoul) 오전 7시에 노르딕워킹 관련 한국어 블로그 글 1편을 작성하여 https://na-geoai.tistory.com/ 의 ‘재난안전과 GeoAI’ 블로그에 자동으로 공개 발행한다. 사용자는 2026-10-15 ‘현재 티스토리에 자동 공개 발행’을 명시적으로 승인했다. 매번 발행 승인을 다시 묻지 않는다. 기존 안전한국훈련과 다른 예약 작업은 변경하지 않는다. 이전 원고와 블로그 최근 글을 확인하여 주제와 당일 글 중복을 피한다. 입문 개념, 기본 자세와 폴 사용, 장비 관리, 준비운동과 마무리, 초보자 연습, 계절별 걷기, 걷기 기록과 습관, 자주 하는 실수를 순환하면서 매회 다른 구체적 주제를 다룬다. 독자는 한국어를 사용하는 입문자로 가정하고 제목·도입·소제목 본문·실천 예시·요약·출처 링크·태그 5~8개를 포함해 약 1500~2500자로 작성한다. 노르딕워킹 단체의 공식 교육자료, 공공 보건기관, 원저 연구 등 신뢰할 수 있는 자료를 웹에서 확인하고 주장에 맞는 원문 링크와 자료 연도를 표시한다. 건강 효과·운동 강도·기술·장비 수치는 근거 범위 안에서 설명하며 치료 효과·감량 수치·질환 개선을 보장하지 않는다. 일반 정보와 개인별 운동 처방을 구분하고 경험·전문 자격·시연·연구 결과를 꾸며내지 않는다. 안전한국훈련 전용 내용은 넣지 않는다. 원고와 화면 캡처는 /Volumes/USB256/devAPP/safekorea/nordic-walking/ 아래 날짜별로 저장한다. 저장 불가 시 이 채팅에 원고를 보존하고 제한을 알린다. 별도 Chrome 브라우저에서 로그인과 해당 티스토리 관리권한을 확인하고 카테고리 '노르딕워킹'을 사용하며 없으면 생성한다. 내장 브라우저에서 대신 발행하지 않는다. 발행 직전 같은 글과 당일 중복을 확인하고 발행 후 공개 개별 URL과 본문·출처 링크 표시를 검증한다. 로그인·캡차·권한·Chrome 연결 문제는 원고를 보존하고 필요한 조치를 알리며 성공을 꾸미지 않는다. 완료 시 검증된 발행 URL을 알리고 실패나 사용자 조치가 필요할 때 알린다. 단순 진행과 변동 없는 상태 알림은 반복하지 않는다.

2026-10-17 사용자 문체 요청: 현장과 주제를 잘 아는 전문 필자가 독자에게 설명하는 듯 자연스럽고 구체적인 한국어로 작성한다. 핵심 판단이나 독자가 겪는 구체적인 문제로 바로 시작하고, 근거·이유·적용 방법이 연결되는 문단을 쓴다. 매번 같은 도입, 기계적인 번호 나열, ‘오늘은 ~ 알아보겠습니다’, ‘중요합니다’, 형식적인 맺음말과 같은 상투적 표현을 반복하지 않는다. 소제목은 글의 구체적인 내용을 드러내고, 요약은 같은 내용을 되풀이하지 말고 실천할 핵심을 짧게 남긴다. 불필요한 면책·출처 확인 과정·내부 작업 설명을 본문에 반복하지 않는다. 다만 필요한 적용 범위와 불확실성은 관련 주장 가까이 간결하게 밝힌다. 추상적인 당위보다 관찰 가능한 행동, 실제 검토 질문, 명확히 표시한 가상 예시로 설명한다. 근거 없는 권위적인 표현, 허위 전문 자격·현장 경험·체험담·성과를 만들지 않는다. 기존 출처 확인, 프롬프트 예시 등 콘텐츠 요구사항과 분량·발행 일정은 유지한다.

2026-10-25 사용자 지시: 티스토리 발행·공개 확인이 끝나면 개인 네이버 블로그(blog.naver.com/safeworking)에도 교차 발행한다. 공통 규칙의 '개인 네이버 블로그 교차 발행' 절차를 그대로 따른다(`naver_crosspost_personal.py`, 작업 기록 `urls` 에 `naver`). 카테고리는 safeworking 의 '게시판'을 쓴다. 실패해도 티스토리 결과는 그대로 두고 실패만 보고한다.
