게임 실습에서 이동, 충돌과 다시 시작을 확인함

작성·갱신: 2026년 11월 11일 | 재난안전과 GeoAI

그림과 동작 규칙을 분리해 설계함

횡스크롤 게임을 만들 때는 캐릭터 그림을 표시하는 작업과 게임의 상태를 계산하는 작업을 나누는 것이 좋음. 캐릭터 ID, 현재 위치, 이동 속도와 체력을 별도로 관리하면 그림을 선택한 결과가 실제 플레이에 반영되는지 확인하기 쉬움. 이미지를 화면에 띄웠다는 사실만으로 캐릭터 선택 기능이나 충돌 처리가 구현된 것으로 보지 않음.

이번 교재의 요구사항은 선택, 이동, 점프, 장애물 충돌, 체력, 점수, 일시정지와 다시 시작을 포함함. 그러나 기존의 짧은 시연 영상이 모든 요구사항을 검증하는 자료는 아님. 게임의 상태 변화와 다시 시작을 살펴보는 영상과, 특정 설정을 수정한 뒤 수행한 검사는 구분해야 함.

입력 조건과 기대 동작을 한 쌍으로 기록함

확인 항목입력과 확인할 내용
이동방향키 입력에 따라 위치가 바뀌는지 확인함
점프바닥에서 점프한 뒤 다시 착지하는지 확인함
충돌장애물 접촉 시 정한 체력 규칙이 적용되는지 확인함
일시정지정지 중 게임 상태가 변하지 않고 재개되는지 확인함
다시 시작위치, 체력, 점수와 진행 상태가 초기화되는지 확인함

이 표는 확인 계획임. 실제로 실행하지 않은 항목을 통과한 결과로 표시하지 않음. 장애물에 닿는 동안 매 프레임 체력이 줄어드는지, 일시정지 중 점수가 계속 증가하는지와 같이 여러 기능이 만나는 조건도 살펴봄. PC와 휴대전화에서 입력 방식이 다르면 각각 확인함.

점프 수정은 관련 조건을 함께 살펴봄

점프 높이를 조절할 때는 높이에 영향을 주는 초기 속도, 중력이나 시간 계산 방식을 코드에서 먼저 확인함. 특정 숫자를 모든 게임에 공통으로 적용하지 않음. 같은 값이라도 화면 좌표의 방향과 시간 단위, 프레임 갱신 방식에 따라 동작이 달라질 수 있기 때문임. 변경 전 값과 제안 값을 기록하고 점프 관련 설정만 수정함.

점프 높이에 영향을 주는 설정을 찾아 설명해줘.
원본을 보존하고 점프 관련 설정만 수정해줘.
장애물 간격과 점수 규칙은 유지해줘.
이동, 점프, 착지, 충돌과 다시 시작을 확인해줘.
실행하지 못한 검사는 미확인으로 기록해줘.

수정 뒤에는 점프가 높아졌는지만 보지 않고 장애물을 통과할 수 있는지, 바닥 아래로 빠지지 않는지, 충돌 판정이 어긋나지 않는지도 확인함. 개발 도구가 코드를 수정한 사실과 브라우저에서 동작을 관찰한 사실은 따로 기록함.

외부 캐릭터의 이용조건을 확인함

제천10경 캐릭터의 출처는 제천시 공식 안내임. 교재 제작 당시 확인 기록에는 출처표시, 상업적 이용금지와 변경금지 조건이 남아 있음. 원본 이미지를 보존했다고 해서 상업적 사용이나 임의의 변형까지 허용되는 것은 아님. 다른 프로젝트에 적용할 때는 해당 자료의 현재 이용조건과 별도 허락 여부를 다시 확인함.

이 사이트에서는 캐릭터가 보이는 게임 영상 3개를 광고 없는 교육용 시연 페이지에 모았음. 이 분리는 별도의 상업적 이용 허락을 취득했다는 의미가 아님. 광고나 판매용 결과물에 캐릭터를 사용하려면 권리 확인을 먼저 진행해야 함.

보고서로 옮길 기록을 남김

사용한 자료, 구현한 기능, 실제 확인 결과와 남은 문제를 순서대로 정리함. 예를 들어 ‘다시 시작 기능을 구현함’과 ‘체력과 점수가 초기화되는 것을 확인함’은 다른 단계의 기록임. 이 차이를 남기면 보고서의 수행 과정과 검증 결과를 구분할 수 있음. 교재 9~11단원의 프롬프트를 사용해 자신의 확인 계획을 작성할 수 있음.
