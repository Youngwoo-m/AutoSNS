보고서의 근거는 실제 활동 기록임

AI 활용 보고서는 수행한 활동을 설명하는 문서임. 프로그램이 생성한 문장이 자연스럽더라도 실제로 실시하지 않은 수업이나 실험이 결과에 포함되면 안 됨. 사용한 자료, 요청문, 변경 파일, 실행 화면과 확인 결과를 먼저 모으고 보고서 항목에 맞춰 분류함. 부족한 내용은 ‘추가 확인 필요’로 남김.

이 교재의 예시는 실습 목적, 자료와 도구, 수행 과정, 확인 결과, 개선할 점을 정리하는 흐름임. 교사가 적용할 수 있는 수업 제안과 실제 학생에게 적용한 결과는 구분함. 학습 효과, 만족도나 작업시간을 조사하지 않았다면 수치나 성과를 만들어 넣지 않음.

양식 원본과 작성 결과를 나눔

HWPX 스킬은 지정한 문서의 내용을 읽거나 양식에 맞춰 결과를 작성하는 데 사용할 수 있는 작업 지침과 도구임. 스킬이 있다는 사실만으로 모든 한글 양식을 동일하게 처리할 수 있는 것은 아님. 문서 구조, 표와 글상자, 포함된 객체를 확인하고 해당 스킬이 지원하는 절차를 살펴봄. 지정한 스킬의 원본은 gonggong_hwpxskills 저장소에서 확인할 수 있음.

원본 양식은 별도로 보존하고 새 파일에 결과를 저장함. 제목과 표의 항목, 병합 셀과 서식이 중요한 양식에서는 전체 문서를 새로 만드는 방식보다 필요한 항목에 내용을 맞추는 방식이 적절할 수 있음. 자료의 분량이 양식의 칸을 넘으면 글자 크기를 과도하게 줄이기보다 문장을 다듬거나 허용된 별지를 사용하는 방법을 검토함.

항목별 입력 자료를 준비함

보고서 항목준비할 근거
실습 목적이번 작업에서 해결하려던 문제와 대상
자료와 도구실제 사용 파일, 출처와 도구 이름
수행 과정요청, 개발, 수정과 확인의 순서
확인 결과실행해 관찰한 내용과 미확인 항목
개선할 점남은 문제와 다음에 검토할 작업
공용 HWPX 스킬의 SKILL.md와 출처를 확인해줘.
제공한 report-template.hwpx의 제목, 표와 서식을 유지해줘.
실제 활동 기록과 확인 결과로 보고서를 작성해줘.
실시하지 않은 수업 효과나 실험 결과를 만들지 마.
원본을 보존하고 결과는 새 파일로 저장해줘.
구조 검사와 실제 한글 화면 확인 결과를 나눠 알려줘.

검수 수준을 구분함

  1. 파일 확인: 결과 파일이 생성되고 열 수 있는지 확인함
  2. 구조 확인: 문서 내부의 항목과 참조가 유지되는지 확인함
  3. 실제 앱 확인: 한글에서 문서를 열고 저장·쪽수를 확인함
  4. 화면 확인: 표 넘침, 글자 잘림, 그림과 캡션의 배치를 살펴봄
  5. 내용 확인: 원자료와 보고서의 사실·수치·출처를 대조함

압축 패키지나 XML 검사가 통과했어도 실제 한글 화면의 글자 잘림까지 확인된 것은 아님. PDF로 내보내는 경우에는 내보내기 성공과 전체 쪽의 시각 검토도 구분함. 확인하지 않은 단계는 결과에 포함하지 않음.

최종 제출 전에 출처와 개인정보를 살펴봄

외부 그림을 사용했다면 출처뿐 아니라 이용조건도 확인함. 다른 사람의 이름, 연락처, 서명이나 학생 정보를 근거 없이 채우지 않음. 교육용 예시는 실제 학생 보고서와 구분하여 표시함. 교재 12~14단원에서 관련 요청과 기존 보고서 작성 기록을 살펴볼 수 있음.
