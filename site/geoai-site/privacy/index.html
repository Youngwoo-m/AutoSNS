개인정보처리방침

시행일 2026년 11월 6일

재난안전과 GeoAI(이하 "운영자")는 이 사이트(geoai-na.web.app)와, 운영자가 자기 블로그·채널에 글과 영상을 올리려고 쓰는 발행 도구 AutoSNS에서 다루는 정보를 아래와 같이 처리합니다.

1. 사이트에서 처리하는 정보

구분항목목적
방문 통계방문 페이지, 접속 기기·브라우저 종류, 대략적인 지역(Google Analytics 쿠키)어떤 글이 도움이 되는지 파악
광고광고 쿠키(Google AdSense)광고 표시와 사이트 운영비 충당
문제 접수이용자가 직접 적은 문제 내용, 분야, 참고 링크, 선택한 닉네임학습용 모범답안 작성·공개

문제 접수 양식에는 연락처나 이름 같은 개인정보를 적지 않도록 안내합니다. 닉네임은 공개 목록에 표시하지 않습니다. 접수한 문제를 바탕으로 쓴 모범답안은 블로그에 공개되며, 이용자는 접수할 때 이에 동의합니다.

쿠키는 브라우저 설정에서 거부하거나 지울 수 있습니다. 맞춤 광고는 Google 광고 설정에서 끌 수 있습니다.

2. AutoSNS 발행 도구와 Google 계정 정보

AutoSNS는 운영자 한 사람이 자기 계정에만 쓰는 도구입니다. 다른 사람의 Google 계정에 접근하지 않습니다. 운영자가 직접 허용한 범위에서 다음 Google API를 씁니다.

  • Blogger API: 운영자 블로그에 글을 올리고, 올라간 글을 확인합니다.
  • YouTube Data API: 운영자 채널에 영상을 올리고, 공개 상태·댓글·조회 통계를 확인합니다.
  • Search Console API: 운영자 사이트의 검색 노출·색인 상태를 읽습니다(읽기 전용).

이렇게 받은 정보는 위 목적에만 쓰고, 판매하거나 다른 곳에 넘기지 않으며, 광고나 사람 분석에 쓰지 않습니다. AutoSNS가 Google API로 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

접근 토큰은 운영자 컴퓨터에 암호화해 보관하며, 인터넷에 공개된 곳에 두지 않습니다. 권한은 언제든 Google 계정 → 타사 앱 및 서비스에서 철회할 수 있습니다.

3. 보관 기간

  • 방문 통계: Google Analytics의 실제 보관 설정과 서비스 정책에 따릅니다.
  • 문제 접수 내용: 모범답안을 작성·공개하는 동안 보관하며, 삭제를 요청하면 지웁니다.
  • AutoSNS 토큰: 도구를 쓰는 동안 보관하고, 권한을 철회하거나 도구를 그만 쓰면 지웁니다.

4. 처리를 맡기는 곳

사이트 호스팅은 Google Firebase, 방문 통계는 Google Analytics, 광고는 Google AdSense가 맡습니다. 이 서비스들은 각 회사의 개인정보처리방침에 따라 정보를 처리합니다.

광고·외부 서비스 관련 추가 안내

갱신일: 2026년 11월 11일

Google AdSense와 Google Analytics를 사용하면 Google 등 제3자가 쿠키, 웹 비콘, IP 주소나 기기 식별자 등을 이용하여 광고 제공, 측정과 서비스 운영에 필요한 정보를 수집·이용할 수 있음. 광고 제공 과정에서 제3자가 이용자의 브라우저에 쿠키를 저장하거나 읽을 수 있음. 자세한 내용은 Google 파트너 사이트와 앱에서의 데이터 사용 및 Google 개인정보처리방침을 확인함.

광고 맞춤설정은 Google 내 광고 센터에서 관리할 수 있으며, 브라우저 설정에서 쿠키를 제한하거나 삭제할 수 있음. 지역과 서비스 설정에 따라 동의 관리 화면이 제공될 수 있음.

쿠팡 파트너스의 링크나 위젯을 이용하면 쿠팡 측에서 링크 연결, 제휴 실적 확인과 서비스 제공에 필요한 정보를 처리할 수 있음. 외부 사이트의 정보 처리는 해당 서비스의 개인정보처리방침에 따름. 사이트의 제휴 영역에는 수수료가 발생할 수 있음을 표시함.

문제 접수 기능은 제목, 문제 내용, 분야, 참고 링크, 선택한 닉네임, 공개 동의 여부와 접수 시각을 처리함. 이름·연락처·학생 정보·비밀키 등은 적지 않도록 안내함. 제출 내용을 바탕으로 학습용 답안을 작성·공개하며, 닉네임은 공개 목록에 표시하지 않음. 문의 이메일에 직접 포함한 이메일 주소와 내용은 문의 확인과 답변을 위해 처리됨.

접수 자료의 열람·정정·삭제 요청과 개인정보 문의는 ds2eye@gmail.com으로 보낼 수 있음. 방문 통계와 제3자 서비스의 보관은 각 서비스의 설정과 정책에 따름. 이 페이지는 현재 공개 기능에 대한 안내이며, 기존 접수 자료가 자동으로 삭제됐다는 뜻은 아님.

사이트 소개 및 작성 원칙문의·오류 신고개인정보처리방침이용 안내
