운영 목적

재난안전과 GeoAI는 공간정보와 인공지능을 재난안전 업무와 학습에 사용하는 방법을 정리하는 개인 운영 교육 사이트임. AI 도구의 실습, GIS와 공간정보의 활용, 재난안전 분야의 학습자료를 연결함. 공공기관이나 도구 제작사의 공식 서비스와 구분되는 독립된 사이트임.

이용할 수 있는 자료

  • 고교 교사와 학생을 위한 AI 활용 교재와 학습 해설
  • 실제 웹앱 및 기존 프로그램 작업 기록을 보여주는 시연
  • 기술사 문제 요청, 발행된 학습용 답안과 자료 안내
  • 운영자가 발행하는 블로그와 영상 채널의 관련 자료

작성과 검수 원칙

자료의 초안 작성과 편집에 AI 도구를 활용함. 확인된 사실, 학습용 예시와 적용 제안을 구분하여 읽을 수 있도록 출처와 확인 범위를 함께 기록함. 파일 생성, 실제 앱 열기, 화면 확인과 기능 실행은 다른 검수 단계로 취급함. 수행하지 않은 검사나 학생의 학습 효과를 확인한 결과처럼 제시하지 않음.

시연 중 공식 화면을 확인하거나 실제 실행 기록을 조회한 장면은 터미널의 직접 조작 녹화와 구분해 표시함. 설치 화면과 도구의 기능은 변경될 수 있으므로 실습 시점의 공식 문서도 확인해야 함. 자료에 오류가 있거나 출처 확인이 필요하면 문의 페이지를 통해 내용을 알려줄 수 있음.

외부 자료와 광고

외부 그림, 문서와 도구는 각 제공처의 권리와 이용조건을 따름. 제천시 캐릭터가 보이는 게임 시연은 광고 없는 교육용 페이지에 분리함. 사이트의 자체 설명과 외부 자료의 이용조건은 서로 다르므로 자료 전체를 자유롭게 재판매·변형할 수 있다고 해석하지 않음.

사이트에는 Google 광고와 제휴 링크가 포함될 수 있음. 제휴 수익이 발생할 수 있는 영역에는 이를 표시하며, 학습 내용과 광고를 구분함. 광고주 또는 상품 추천을 공식적인 검증이나 성능 보증으로 해석하지 않음.
