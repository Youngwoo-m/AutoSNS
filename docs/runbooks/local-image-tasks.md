# 로컬 카드·절차 도식 제작

개인·학과 콘텐츠의 원고 편집기에서 ‘로컬 이미지 제작’ 패널을 펼친다. 카드 또는 절차 도식을 고르고 제목, 줄별 본문 1~6개, 하단 문구를 입력한 뒤 명시적으로 제작한다. 결과는 PNG 1080×1350이며 개인·학과 색상과 계정 표시는 서버 원고 소유자에 따른다. 외부 사진 검색·유료 API·모델 호출은 없다.

기본 8769 서버에서는 제작이 비활성이다. 화면과 저장된 작업 조회를 사용할 수 있으며, 실제 제작은 신뢰된 로컬 제작기 등록과 명시 기동 옵션이 필요하다. 설치된 Chromium의 절대 실행 경로를 고정하여 자동 다운로드를 사용하지 않는다. 공통 axlock의 renderer:local-card 잠금은 임시 렌더 브라우저끼리의 충돌을 막는다. 개인·학과 로그인 프로필은 열지 않는다.

제작 요청은 콘텐츠·버전·입력별로 멱등 처리한다. native 호출 전에 started를 저장한다. started/unknown을 자동 재실행하지 않는다. rendered 상태에서는 ‘결과 등록’만 재개하고 PNG를 다시 만들지 않는다. 완료된 요청을 다시 제출해도 같은 작업을 돌려준다. 결과 등록은 원고 CAS를 사용하여 새 버전을 만들며, 원고가 바뀌면 덮어쓰지 않는다.

제작 결과의 경로·바이트·PNG 크기·해시를 검증하고 내부 작업 원장에 generated 출처를 보존한다. 기술 검사 통과는 사실·출처·시각 품질 검토가 아니다. 결과 등록 후 최신 버전을 열어 PNG를 확인한다. 영상 장면에 사용하려면 기존 이미지 재사용 확인을 별도로 기록한다.

현재 개발 검증은 가짜 PNG 공급자와 격리 저장소·HTTP 및 DOM 시험이다. 실제 렌더 품질, 한글 넘침·가독성·배치, 실제 브라우저 설치와 운영 기동 수락은 아직 완료하지 않았다. 임의 이미지나 디오라마를 생성하는 AI 이미지 공급자는 이 로컬 텍스트 카드 제작기와 별도 범위다.

고정 기동 설정은 `ax-console/config/image-renderer.json`이며 기본 `enabled=false`, `browser_executable=null`이다. `production_main.py --serve --enable-images --image-config <절대 설정 경로>`에서만 읽는다. 활성 설정과 명시 브라우저 실행 파일이 없으면 모델·runtime 조립 전에 거부한다. `--check`는 설정을 읽어 제작기를 활성화하지 않는다. 서버 코드에서 신뢰된 `ImageRegistration`을 주입하는 방식도 제공한다.

STOP 파일은 렌더 호출 전 조기 확인한다. renderer 작업은 발행 작업이 아니므로 기존 axlock 정책의 발행 STOP 원자 차단과 동일한 보장은 하지 않는다. 실제 제작 중단 정책의 최종 운영 수락은 별도로 남아 있다.
