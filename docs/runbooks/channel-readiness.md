# 채널별 연결 준비 상태

개인·학과 계정 연결 화면의 ‘채널별 연결 준비 상태’를 펼치면 현재 서버 등록부와 저장된 OAuth 연결 기록만 조회한다. 미등록 계정·채널은 가짜 연결 ID를 만들지 않고 ‘연결 없음’으로 표시한다. 기본 등록부의 실제 연결 11개와 미등록 조합 7개를 구분한다.

발행·공개 확인·성과 코드가 개발된 상태와 대상 ID·인증 기록, 실제 관리 웹 실행 상태는 서로 다르다. ‘연결 기록 있음’은 현재 로그인 성공을 뜻하지 않는다. 이 패널은 관리 웹의 준비 범위이며 원본 launchd 자동 작업의 실제 실행 상태를 대변하지 않는다. 원본 작업 상태는 기존 자동 작업 화면에서 확인한다.

조회는 자격 읽기·앱 시작·외부 API·발행을 실행하지 않는다. 접힌 상태에서는 GET도 하지 않으며, 계정 전환 후 도착한 이전 응답은 무시한다. 다음 조치에는 실제 연결·게시·공개 확인 시험과 아직 개발이 남은 부분을 표시한다.

관리 웹의 실제 발행 활성화는 여전히 하지 않았다. 현재 표시를 실계정 운영 수락 완료로 보지 않는다.
