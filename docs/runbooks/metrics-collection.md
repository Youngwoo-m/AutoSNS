# 공개 게시물의 성과 수집

성과 화면의 접힌 ‘공개 게시물 성과 수집’을 펼치면 대상 목록만 조회한다. 대상은 원장에서 공개 검증 완료된 게시물 중 서버 수집기가 등록된 연결이다. 계정 필터는 실제 발행 대상 계정 기준이므로 개인 콘텐츠를 학과 채널에 교차 발행한 기록은 학과 대상에 나타난다.

게시물을 선택해 수집을 누르면 delivery_id만 서버로 보낸다. 서버는 원격 ID·채널·계정·수집기를 원장과 등록부에서 조회하고, 프로필·계정·연결 잠금 안에서 원장을 다시 확인한 뒤 한 번 수집한다. 발행·원고·예약 상태는 바꾸지 않으며 자동 반복 조회나 재시도는 하지 않는다. 요청 결과가 불명확하면 목록과 저장 성과를 먼저 다시 확인한다.

YouTube는 인증된 불변 채널과 단일 영상 ID·공개 상태를 확인한 뒤 조회수, 제공되는 좋아요·댓글 수를 lifetime 관측으로 저장한다. 누락된 선택 수치를 0으로 만들지 않는다. 외부 응답·자격·예외 원문은 저장하지 않고 실패는 값 없는 오류 관측으로 구분한다. 서로 다른 관측 정의·기간·채널 수치는 합산하지 않는다.

기본 기동은 수집 서비스가 없고, `ax-console/config/metrics-collection.json`도 비활성이다. 신뢰된 설정에서 enabled와 personal.youtube/dept.youtube 연결을 명시한 뒤 `production_main.py --serve --enable-metrics --metrics-config <절대 경로>`로 기동해야 수집 요청을 받을 수 있다. 텍스트·이미지·음성·영상 제작·발행 활성화와 독립적이다. `--check`는 API·자격·실제 수집을 호출하지 않는다.

기본 서비스 factory는 실제 수집 요청 시에만 기존 계정별 암호화 Google 자격을 읽는다. 기존 동의 범위에서 토큰을 갱신할 수 있으나 새 OAuth 동의나 타 계정 fallback은 하지 않는다. 원본 shared/axlock의 프로필 잠금은 유지한다. 성과 읽기는 발행이 아니므로 발행 STOP 예외 확인 없이 읽기 잠금을 사용한다.

검증은 가짜 Google SDK·임시 원장·가짜 자격과 HTTP/DOM 시험이다. 실제 API 수치 수락·OAuth 자격 연결·추가 채널 수집·외부 접속은 아직 미완료다.
