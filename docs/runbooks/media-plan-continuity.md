# 음성 제작 뒤 장면 계획 이어 쓰기

음성 합성이 완료되면 WAV를 포함한 새 원고 버전이 생긴다. 이전 버전의 제작 계획은 변경하지 않는다. 최신 버전을 열고 ‘숏츠 제작 계획’에서 이전 버전 번호를 입력해 계획을 조회한 뒤 ‘이전 계획 가져오기’를 누른다.

새로 생성된 WAV를 현재 음성 선택란에서 선택하면 가져올 계획의 음성을 그 WAV로 바꾼다. 선택하지 않으면 이전 계획의 음성을 유지한다. 장면·자막 등 다른 미저장 변경이 있으면 먼저 저장하거나 버린다. 가져오기는 현재 계획을 CAS 갱신하므로 이미 저장된 계획이 있으면 명시적으로 그 계획을 대체한다.

서버는 같은 콘텐츠와 소유자, 과거 계획의 조회 시점 계획 버전, 대상 계획의 버전, 최신 원고 여부를 대조한다. 사용 이미지와 유지하는 음성은 두 버전의 실제 파일 바이트·해시·크기·형식을 검증한다. 새 음성도 대상 버전에 등록된 WAV여야 한다. 파일이 없거나 바뀌면 가져오기를 거부한다.

계획 가져오기는 제작 실행·재합성·렌더·승인·발행을 실행하지 않는다. 이미지 재사용 확인과 최종 영상·원고 검토는 각각 유지한다. 예전 계획에 대한 검토 결과를 새 버전의 검토로 복사하지 않는다.

다른 창에서 계획이나 원고가 바뀌어 충돌하면 입력을 유지한다. 최신 원고와 저장 계획을 다시 확인한 뒤 명시적으로 재시도한다. 자동 재시도하지 않는다.

저장소 경합 범위: 이전·대상 계획 버전 비교와 계획 저장은 한 미디어 DB 트랜잭션에서 처리한다. 콘텐츠 저장소는 별도 DB이므로 최신 버전을 검증 전·저장 직전에 재확인한다. 직후 다른 콘텐츠 버전이 만들어져도 계획은 요청한 고정 버전에만 저장되며 새 원고를 덮어쓰지 않는다.
