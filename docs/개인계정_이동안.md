## 2. 먼저 풀어야 할 문제

1. **중복**: `GeoAI_NA/naver-blog-auto/` 의 `tistory_*.py`·`run_tistory.sh` 는 `dept/…` 와 내용이 같다(cmp 확인). launchd 는 `channels/naver-blog-auto/run_tistory.sh`(=dept) 를 부른다. `tistory_patch.py` 만 GeoAI_NA 쪽에만 있다. 이동 때 한쪽으로 합친다.
2. **공용 모듈**: `common.py`·`config`·`.venv`·`chrome-profile*` 은 dept·personal 이 함께 쓴다. 파일을 옮기면 `import common` 이 깨지므로 ① 개인 쪽에서 `../../dept/naver-blog-auto/common.py` 를 심볼릭 링크하거나 ② `common/` 으로 올린다. ①로 시작하는 것을 권한다.
3. **크롬 프로필 경로**: `common/shared/axlock.py` 의 `RES_PROFILES`(safeworking·tistory)와 `AGENTS.md` 표가 옛 경로를 가리킨다. 프로필 폴더는 **옮기지 않고** 경로만 유지하면 로그인이 풀리지 않는다(.gitignore 대상).
4. **launchd 6개**: `geoai.daily`, `geoai.evening`, `tistory`(+ claude 작업은 이미 `GeoAI_NA/` 경로). plist 의 ProgramArguments 를 새 경로로 고쳐 재등록한다.
5. **하드코딩 절대경로**: dept/disaster-shorts 가 `channels/youtube-shorts-auto` 를 직접 가리키는 곳 9곳(1단계 조사). 숏츠 폴더를 가르면 학과 쪽 참조를 먼저 점검한다.

## 3. 순서 (한 단계씩 커밋, 단계마다 launchd 재등록·dry 점검)

1. `GeoAI_NA/*` → `personal/` (경로가 이미 GeoAI_NA 하나라 위험이 가장 작다). 옛 경로는 심볼릭 링크.
2. 티스토리 중복 정리 + `tistory_*` 를 `personal/blog-auto/` 로. `run_tistory.sh` 먼저, 18:50 회차 전후가 아닌 시간대(예: 10:00~17:00)에.
3. `geoai_*`·Blogger·safeworking 이동, `common.py` 는 링크로 유지.
4. 숏츠 `geoai_*` 이동, 학과 쪽 참조 점검.
5. `AGENTS.md`·`docs/폴더지도.md`·`axlock.py` 문구 갱신, `site/geoai-site` 이동 여부 결정.
