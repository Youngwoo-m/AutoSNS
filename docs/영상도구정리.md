# 영상 제작 도구 정리 (2026-10-21)

클로드로 영상을 만들 때 쓰는 도구 5가지의 설치 상태와 사용법. 이 프로젝트의 영상 편집 기본은
CLAUDE.md 의 **Remotion**이다. 나머지는 용도가 다를 때 보조로 쓴다.

| 도구 | 설치 상태 | 한 줄 용도 |
|---|---|---|
| Remotion 스킬 | 설치됨 (`~/.agents/skills/remotion-*`) | 숫자·그래프·자막이 움직이는 영상. **프로젝트 기본** |
| HyperFrames | 설치됨 (`~/.claude/skills/hyperframes*`) | HTML 화면을 그대로 MP4 로 |
| motion-graphics | 설치됨 (`~/.claude/skills/motion-graphics`) | 10초 안팎 모션 그래픽·로고·통계 카운트업 |
| Manim | 설치됨 (`~/.venvs/manim`, Manim 0.22.0) | 수학·공식 설명 애니메이션 |
| Blender MCP | 설치됨 (Blender 4.5.14 + MCP `blender`) | 말로 3D 장면·회전 영상 |

## 1. Remotion (기본)
- 시작: `remotion-best-practices` 를 먼저 읽고 `remotion-create`(새 영상) → `remotion-captions`(자막)
  → `remotion-render`(출력) 순서로 쓴다.
- 이 저장소: `remotion-shorts/` 에 템플릿, `render_survey_short.py` 로 렌더.
- 요청 예: "survey-short 템플릿으로 오늘 문제 숏츠 만들어 줘."
- 영상마다 디오라마 이미지 2~3장, Pretendard Bold, AI 합성 고지(CLAUDE.md 영상 지침).

## 2. HyperFrames
- 웹(HTML) 화면을 시간축으로 재생해 MP4 로 뽑는다. 제품 소개·사이트 투어·캡션 영상에 맞다.
- 요청 예: "이 URL 로 30초 홍보 영상 만들어 줘" → `/hyperframes` 가 알맞은 하위 흐름을 고른다.
- 직접 쓸 때: `hyperframes-cli` 의 init → preview → check → render.
- 원본 안내의 설치 명령(이미 설치됨, 재설치 불필요):
  `claude plugin marketplace add heygen-com/hyperframes` / `claude plugin install hyperframes@hyperframes`

## 3. motion-graphics
- 짧은(대개 10초 이하) 디자인 중심 영상: 글자 모션, 숫자 카운트업, 차트, 로고 스팅, 하단 자막띠.
- 요청 예: "합격률 87% 가 올라오는 8초짜리 카운트업 영상, 투명 배경 오버레이로."
- 길거나 내레이션이 있으면 `general-video`, 애매하면 `hyperframes` 로 시작.

## 4. Manim (설치됨)
- 실행: `~/.venvs/manim/bin/manim -qh --media_dir <출력폴더> remotion-shorts/manim/error_propagation.py ErrorPropagation`
- 샘플: `remotion-shorts/manim/error_propagation.py` (세로 1080x1920, 약 10초, 오차 전파 σz=√(σx²+σy²)). LaTeX 없이 Text 로 쓰고 Pretendard Bold 를 등록한다.
- 렌더한 mp4 는 Remotion 장면 사이에 `<OffthreadVideo>` 로 넣는다.
- 수학·공식 설명(예: 오차 전파, 좌표 변환)을 그리는 파이썬 애니메이션 엔진. 측량 숏츠에 쓸 만하다.
- 설치 방식: `/usr/local/bin/python3.12` 로 만든 가상환경 `~/.venvs/manim` 에 `pip install manim`
  (cairo·pango 는 휠에 포함돼 brew 설치가 필요 없었다).
- MCP 서버(abhiemj/manim-mcp-server)는 외부 개인 저장소라 설치하지 않았다. 클로드가 Manim 코드를
  직접 써서 `manim -qh` 로 렌더하면 MCP 없이도 된다.

## 5. Blender MCP (설치됨)
- 말로 3D 장면을 만들고 회전 영상을 뽑는다. 영상 지침의 디오라마는 2D 이미지라 당장 필수는 아니다.
- 설치 내용: Blender 4.5.14(`/Applications/Blender.app`), `uv`(pip, `~/.local/bin/uv`), Claude Code 사용자 범위
  MCP `blender`(`uvx mcp-for-blender`, 텔레메트리 끔), Blender 애드온 `blender_mcp_addon` 활성화.
  Codex·VS Code·Claude Desktop 설정은 건드리지 않았다.
- 쓰는 법: Claude Code 를 껐다 켠 뒤 Blender 를 열고 사이드바(N) → MCP 탭에서 서버를 시작하고,
  "큐브가 천천히 회전하는 5초 영상 만들어 줘" 처럼 요청한다. 에셋은 Poly Haven(CC0)에서 받는다.
- 시험 결과(2026-10-22): Blender 를 열면 약 10초 뒤 포트 9876 에서 서버가 자동으로 켜진다(`-b` 모드는 불가).
  장면 조회와 회전 큐브 24프레임 렌더(540x960 mp4)까지 소켓으로 확인했다.
- 이 맥(Intel)에서는 **EEVEE 렌더가 Blender 를 종료시켰다.** `engine="CYCLES"`, `cycles.device="CPU"`,
  `samples=16` 으로 렌더하면 된다(24프레임 540x960 에 약 5분). 렌더 중에는 Blender 화면이 멈추고
  MCP 요청이 시간 초과로 보일 수 있으니 파일이 생기는지 확인한다.
- 외부 개인 패키지(ahujasid/blender-mcp)이므로 버전 업데이트 때 코드를 다시 훑어본다.
