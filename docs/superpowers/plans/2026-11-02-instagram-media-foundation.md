# Instagram 미디어 배포 기반 구현 계획

**목표:** 개인·학과 계정의 승인된 이미지·REELS·캐러셀을 기존 미디어 제작/검토/원장 구조와 결속한다. 기존 학과 YouTube→Instagram 3개를 포함한 교차 게시 23개는 유지한다.

현재 `dept.instagram`은 대상 ID가 없는 비활성 계획 연결이며 개인 연결은 미등록이다. 로컬 웹의 로그인 자산 URL은 Meta가 접근하는 공개 URL이 아니다. 공식 API는 미디어 컨테이너 생성·상태 확인·발행을 구분하므로 기존 브라우저의 UI 문구만으로 게시 완료를 판단하는 경로와 별도 구현한다.

## 병렬 작업과 검증

- [x] `instagram_payloads.py` 및 단위 시험: 불변 snapshot/계정/버전/manifest와 고유 Instagram 변형을 결속한다. 명시 `options.instagram={format,asset_ids}`로 단일 JPEG 이미지·단일 MP4 REELS·순서 있는 2~10개 JPEG/MP4 캐러셀을 선택한다. 자동 선택·순서 변경·실패 항목 제외·절단·변환을 하지 않는다. 캡션 2200자는 서버 내부 준비 상한이며 공식 API 한도 수락의 증거가 아니다.
- [x] `instagram_client.py` 및 가짜 transport 시험: 명시 버전·Facebook Login 경로의 계정 ID 관측, 이미지/REELS/캐러셀 컨테이너·상태·발행·알려진 미디어 읽기 경계를 구현한다. 기본 전송은 미등록이며 비밀 비노출·정확한 ID/유형·엄격 JSON·재시도 금지를 검증한다. Instagram Login의 host/scope와 직접 resumable upload는 별도 계약으로 남긴다.
- [x] 공개 미디어 전달 경계: 실제 로컬 자산 바이트를 읽어 크기·SHA256을 검증하고, 신뢰된 서버 공급자가 발급한 공개 HTTPS 주소·동일 바이트 증명·만료·대상/계정/원고/승인 문맥을 결속한다. 기본 공급자는 없고 실제 파일 공개·업로드는 하지 않는다. 임의 사용자 URL·기존 자격 fallback·자동 이미지 변환은 허용하지 않는다.
- [x] 통합 검증과 남은 범위 기록: 가짜 전송/공급자만으로 계약을 검증하고 실제 API·로그인·게시·미디어 렌더를 하지 않는다. 전체 목표의 나머지 채널·성과·계정 경로 이행·외부 접속·종합 수락은 유지한다.

## 후속 필수 연결

발행 전 최종 미디어 검토를 자산별 증거에 결속해야 한다. 현재 이미지 재사용 승인은 소유자/콘텐츠/실제 바이트에 묶이지만 영상 검토 결과는 제작 원장에 있고, 모든 자산에 대한 공통 SNS 최종 검토 모델은 없다. 이번 기반이 검토 완료를 대신하지 않는다.

이후 공개 미디어의 실제 공급자/비용·노출 동의, 컨테이너 생성과 publish 각각의 영속 상태·중단 복구·중복 방지, 실제 원본 전달 영수증과 변환된 원격 미디어의 별도 공개 관측, 공통 승인/실행기와 UI, 실제 Instagram 권한·프로페셔널 계정·대상 확인을 연결한다. 원격 변환 미디어의 바이트 해시를 원본 해시로 합성하지 않는다. Instagram Login과 Facebook Login을 묵시적으로 전환하지 않는다.

근거는 Meta 공식 Business SDK의 IGUser/IGMedia와 공식 Instagram Platform API Postman collection을 따른다. 실제 앱 권한·현행 API 버전·유료 여부·네트워크 수락은 별도로 검증해야 한다.

## 검증 기록과 운영 상태

순수 준비 14개·client 14개·공개 미디어 공급자 경계 9개·세 모듈 조립 2개의 가짜 공급자 시험을 구현했다. 전체 발행 모듈 회귀 289개가 통과했다. 조립 시험은 실제 API나 발행 원장/adapter를 거치지 않으며, 최소 파일 서명 fixture를 실제 미디어 품질 증거로 사용하지 않는다.

등록부 연결 11개·enabled 연결 0개·교차 규칙 23개와 Instagram 대상 legacy 규칙 3개를 재확인했다. 기동 설정·웹 화면·운영 자료·실제 프로필은 변경하지 않았다. 이번 모듈은 아직 기본 웹에 등록되지 않아 8769 서버를 불필요하게 재기동하지 않는다. 실제 제작·파일 공개·SNS 권한·게시·성과 수집 및 전체 목표 수락은 미완료로 유지한다.
