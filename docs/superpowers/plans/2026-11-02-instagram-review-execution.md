# Instagram 최종 구성 검토와 실행 원장

**목표:** 이미지·REELS·캐러셀 계획을 저장하고 실제 선택 자산과 캡션을 사람이 검토한 기록을 발행 경계에서 다시 확인한다. 실제 외부 게시·미디어 공개·로그인은 활성화하지 않는다.

## 병렬 구현

- [x] 최종 검토 저장소/서비스: 별도 append-only `instagram-reviews.sqlite3`, 명시 초기화, 준비된 15개 필드의 canonical 해시에 대한 CAS 검토. 권리·시각·캡션·구성 체크와 영상 포함 시 오디오 체크를 요구한다. 다른 버전·대상·선택 순서·캡션의 검토는 승계하지 않으며 철회는 새 기록이다. 실제 저장된 계획/등록부/원고/선택 자산 바이트를 재조회하고 사용자 입력으로 owner/target/hash/actor를 덮어쓰지 않는다. 원고 독립 검토와 공통 계획/발행 승인은 유지한다.
- [x] 계획 화면/검토 패널: 기존 네 메뉴와 배포 편집기에서만 게시 형식과 순서 있는 자산 ID를 명시 선택한다. 실제 대상이 미확인인 계획 저장은 허용하되 최종 검토는 차단한다. 저장된 Instagram 계획에 접힌 최종 검토 패널을 추가하고, 펼칠 때만 조회한다. 체크·메모와 명시 저장/철회, 실패 시 초안 보존, 변경 중 부모 원고·계획 전환 차단을 구현한다.
- [x] HTTP/API 연결: 인증·동일 출처 검사를 유지한 GET/POST `/api/v2/deliveries/{id}/instagram-review`와 계획 선택 검증을 추가한다. 읽기는 저장소를 만들지 않고 기본 명시 웹 초기화만 검토 DB를 생성한다. 기존 실제 운영 스케줄·교차 경로는 변경하지 않는다.
- [x] Instagram 발행 서비스/leaf 원장: 파일 전달·자식/부모 컨테이너 생성·publish 각각의 시작을 먼저 영속 기록한다. 알려진 컨테이너는 상태만 조회해 재개하고, 응답 유실·중단의 불명확한 POST는 반복하지 않는다. 최종 검토와 계정 권한·URL 만료·쓰기 직전 STOP 주입 경계를 확인한다. 기본 공급자/계정 권한/검토 guard 미등록이면 차단한다. 실제 adapter/native bootstrap·공개 검증 연결은 후속 범위로 명시한다.
- [x] 단위·DOM·격리 HTTP·가짜 공급자 회귀 검증 후 8769 관리 웹의 코드만 반영한다. 로그인 브라우저 검증은 사용자가 거절한 상태를 유지한다. 실제 API·렌더·업로드·SNS 발행은 실행하지 않는다.

## 경계

계획 준비에는 인증 필드가 없는 `InstagramPreparationContext`를 사용하며 가짜 대상 ID나 가짜 인증 관측을 만들지 않는다. 공개 미디어 전달 경계는 계속 실제 `PublicationContext`와 현행 승인 guard를 요구한다. 미확인 대상은 계획 입력/저장 범위에만 머문다.

최종 검토는 검토한 구성의 승인 기록이며, 그 자체가 미디어 공개·네트워크 사용·일회성 게시 permit를 발급하지 않는다. 실제 byte staging 전과 각 원격 쓰기 전 현행 검토/STOP/권한을 다시 확인해야 한다. 사용자 계정·페이지·제공자·scope·비용·실제 호스팅/회수·공개 접근 수락을 추측하지 않는다.

원본 23개 교차 규칙, 그중 Instagram 3개의 legacy 실행 소유권을 보존한다. 이후 전체 목표의 다른 SNS·성과·계정 경로 이행·외부 접속·종합 운영 수락을 계속 진행한다.

## 검증·배포 기록

웹 379개·발행 모듈 312개·운영 모듈 1002개(4개 건너뜀)·HTTP/계획 원장 25개·기존 웹 서버 30개 시험이 통과했다. 인증 없는 계획 문맥으로 실제 공개 전달을 요청해도 loader/stager를 호출하지 않는 추가 회귀를 별도로 검증했다. 실제 저장소부터 검토·공급자·client·전송 원장의 통합은 가짜 외부 공급자만 사용하며 실제 publication permit/native child/public probe 수락의 증거가 아니다.

8769를 같은 비활성 실행 설정으로 재기동했다. 로그인 HTTP 200·무인증 검토 API HTTP 401을 확인했고, 검토 DB schema 1의 명시 초기화를 확인했다. 코드 백업은 `ax-console/data/deployment-backups/instagram-review-7d54432.tar`에 보관했다. 계획 등록부 연결 11개·enabled 연결 0개·교차 규칙 23개와 Instagram legacy 규칙 3개를 유지한다.
