# 음성 제작 뒤 장면 계획 이어 쓰기

기존 4개 메뉴와 제작 패널을 유지한다. 사용자가 이전 콘텐츠 버전을 조회하고, 확인한 계획을 현재 최신 버전에 명시적으로 가져온다. 자동 상속은 하지 않는다. 개발 완성 뒤 종합 검토한다는 사용자 지시에 따라 중간 승인 질문 없이 구현한다.

- 저장소: 같은 콘텐츠·소유자, 이전 버전 및 계획 CAS, 사용 이미지·음성의 실제 바이트 보존을 확인한다. 새 WAV를 명시하면 이전 음성을 대체한다. 대상 계획은 별도 CAS 저장하고 과거 계획은 보존한다.
- HTTP: 기존 media-plan POST에서 정확한 import 명령 스키마를 구분한다. 기존 인증·Origin 보호를 재사용한다. 계정·경로·검토·발행 플래그는 받지 않는다.
- 화면: 이전 버전 번호 입력→계획 조회→가져오기. 기존 미저장 입력이 있으면 가져오기를 막고 먼저 저장하거나 버리도록 안내한다. 응답의 콘텐츠·소유자·버전을 검증한다. 새 음성은 사용자가 기존 음성 선택란에서 선택한다.
- 검증: 저장소 바이트/소유자/계획 경합, 인증 HTTP, UI 조회/명시 POST/경합·오류 입력 보존. 실제 모델·렌더·SNS 로그인·발행은 실행하지 않는다.
