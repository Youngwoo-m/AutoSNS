# 공용 로컬 카드·도식 제작

개인·학과 콘텐츠 제작에 필요한 이미지 제작을 공용화한다. 기존 학과 카드뉴스 제작기는 외부 사진·학과 로고·독립 브라우저 실행에 결합되어 보존한다. 새 경로는 비용 없는 고정 Remotion 정지 이미지 composition을 사용한다. 기존 영상 템플릿은 변경하지 않는다. 제작을 마친 뒤 종합 검토한다는 사용자 지시에 따라 중간 승인 질문 없이 독립 구현을 병렬 진행한다.

입력: template(card|steps), title(80자), body(6개 이하 각120자), footer(120자). 소유자는 서버의 콘텐츠 snapshot에서 정한다. 개인/학과 색상과 계정명만 고정 차등 적용한다. 사실·출처는 입력 그대로 표시하며 모델·외부 사진·임의 HTML·URL·경로를 받지 않는다. PNG 1080x1350 결과를 만들고 검토 전 자산으로 등록한다. 디오라마 생성이나 실제 그림 제작을 완성했다고 주장하지 않는다.

1. 고정 LocalCard composition과 순수 입력 검증/네이티브 runner. 명시 호출 전 import/생성자는 읽기·렌더를 하지 않는다. 고정 소스/글꼴 해시와 기존 Remotion 설치를 확인하고 최소 환경·고정 인수로 실행한다. 실제 렌더는 이번에 실행하지 않는다.
2. 이미지 작업 저장소/서비스. 별도 DB, 기본 비활성, 명시 초기화·제작 버튼만 실행. 콘텐츠+버전+입력의 멱등 키, started/unknown 재실행 금지, 기술 검증 뒤 CAS 자산 등록, 콘텐츠 변경 시 덮어쓰기 금지. 작업에는 generated provenance를 보존하며 자동 권리·시각 검토 완료를 만들지 않는다.
3. 인증 HTTP 및 콘텐츠 편집기 접힌 로컬 이미지 패널. 계정/버전 결속·미저장 보호·오류 입력 유지. 생성 결과의 새 원고 버전 열기만 명시 제공한다. 실제 서비스 기동은 별도 명시 startup 경계에 둔다.
4. 임시 저장소·가짜 leaf의 통합 시험, 인수·해시·형식·계정·경합·기동 비활성 시험. 실제 이미지 품질 검증과 운영 활성화는 후속 필수 작업으로 유지한다.
