# 변환된 YouTube 영상의 공개 검증

현재 영상은 원격 변환 후 원본 파일과 바이트 해시가 달라지므로 공통 해시 비교로 공개 검증이 완료되지 않는다. 원격 해시를 로컬 값으로 채우지 않고, 검증한 업로드 입력과 SDK 응답의 원격 ID를 묶은 서버 영수증을 기존 제출 결과에 저장한다.

1. 실제 미디어 factory가 원고 자산 바이트·해시·크기를 확인한 뒤 typed VerifiedYoutubeMedia를 만든다. 성공한 업로드의 실제 ID를 받은 뒤에만 고정 upload_receipt를 만든다. 과거/가짜 미디어·불명확한 결과에는 영수증을 만들지 않는다.
2. 읽기 관측이 동일 원격 ID·채널·제목·설명을 나타내고 공개·업로드 처리·영상 처리 완료일 때 공개 후보로 반환한다. 일반 검증기가 직접 저장된 성공 제출 attempt와 영수증을 승인된 snapshot/준비 payload에 다시 대조해야 verified가 된다.
3. 기존 예약 시각·관측 시각·버전·공개 상태 검증은 유지한다. receipt 없는 과거 업로드와 unknown 결과를 제목 유사성으로 해소하지 않는다. 영상 변환 후 원격 media_sha256은 None으로 유지한다.
4. 가짜 SDK·영속 원장으로 정상 공개 완료, 타계정/ID/자산/원고/본문 변경·가짜 receipt·예약 전/처리 중/비공개 거부를 검증한다. 실제 인증·업로드·API 수집은 실행하지 않는다.

공식 참고: https://developers.google.com/youtube/data/reference/rest/v3/videos 와 /videos/insert. 공개 검증 영수증 결합은 이 프로젝트의 서버 증거 설계이며 공식 원격 파일 해시 제공 기능을 주장하지 않는다.
