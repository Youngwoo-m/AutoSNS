# 측량및지형공간정보기술사 유튜브 자동 게시 설계

매일 하루 한 문제와 친구 요청 문제의 공개 블로그 글을 한국어 설명 영상으로 제작하여 https://www.youtube.com/@geoai-safety 에 게시한다. 블로그의 실제 공개 발행 시각에서 1시간 뒤 공개하는 것을 목표로 한다. 기존 블로그 발행 일정과 일차는 유지한다.

## 영상 구성

가로형 1920×1080, 총 120~180초의 2~3분 요약 영상으로 제작한다. 왼쪽에는 모범답안 작성면을 크게 보여주고, 오른쪽에는 핵심 설명 문장을 음성에 맞춰 타이핑 방식으로 표시한다. 초기 좌우 비율은 60:40으로 잡고 가독성을 확인하여 조정한다. 왼쪽은 설명 중인 답안 구간을 확대·강조한다. 따라쓰기 PDF 원본은 보존하고 영상 표시본은 읽기 좋은 대비로 표현한다.

문제 소개 → 답안 구조와 핵심 원리·그림·비교표 → 암기어 → 블로그 안내 순으로 구성한다. 오른쪽에는 현재 설명하는 문장만 넣고 긴 문단을 작은 글씨로 채우지 않는다. 한국어 자막과 타이핑을 음성에 맞추고 전문 용어와 수식의 발음을 검수한다. 설명란 첫 줄에는 자세한 모범답안과 PDF가 있는 개별 블로그 글 링크를 넣는다. 마지막 화면과 음성에는 ‘자세한 모범답안과 따라쓰기 PDF는 영상 설명란의 블로그 링크에서 확인하세요’라고 안내한다. 친구 요청 페이지, 공식 참고자료 링크와 학습용 모범답안 안내도 포함한다. 기출 여부와 연도·회차는 검증된 블로그 표기를 그대로 따른다.

한국어 음성은 설치된 Voicebox의 ‘내 목소리 (1샘플)’ 프로필을 사용한다. 확인된 프로필 ID는 9ae4198e-a2c5-4604-9165-7d39adf0143c이다. 다른 음성으로 자동 대체하지 않는다.

## 처리 흐름

1. 공개 검증을 마친 신규 블로그 글의 URL, 발행 시각, 원고와 그림·표 경로를 영상 대기열에 등록한다. 활성화 이전 글의 소급 제작은 별도 요청이 있을 때 수행한다.
2. 글 URL을 고유 키로 사용하여 중복 등록과 재업로드를 방지한다. 영상 작업 상태는 블로그 및 친구 요청 접수 상태와 별도로 보존한다.
3. 블로그 내용을 설명 대본과 화면으로 구성하고 Voicebox 음성을 생성한다. 자막, 그림, 비교표를 합성해 MP4를 만든다.
4. 전체 길이, 음성·자막 동기화, 한글과 수식, 그림·표의 잘림을 확인한다. 원고와 음성, MP4 및 검증 결과를 해당 문제 자료 폴더에 보존한다.
5. 기존 개인 GeoAI 채널 업로드 기능을 활용하되 채널을 확인하고, 일반 가로형 영상에 쇼츠·재난뉴스 전용 문구가 붙지 않도록 메타데이터를 분리한다.
6. 준비가 완료되면 비공개 업로드와 예약 공개 기능을 확인해 발행 시각+1시간 공개를 설정한다. 목표 시각까지 제작이 끝나지 않거나 컴퓨터·네트워크가 중단되면 복구 후 게시하고 지연 사유를 기록한다. 정확한 예약 공개가 지원되지 않으면 이를 알리고 지원되는 실행 방식을 설계에 반영한다.
7. 공개 영상의 채널, 제목, 재생 여부와 설명 링크를 검증한 후 완료로 저장하고 영상 URL을 알린다. 대기 중에는 반복 알림을 보내지 않는다.

## 실패 복구

Voicebox 연결·모델·음성 프로필 오류는 음성 생성 단계에서 보존하고 재시도한다. 업로드 응답이 불확실하면 기존 영상과 로컬 결과를 확인한 후 복구하며 같은 영상을 다시 올리지 않는다. 인증 만료는 필요한 사용자 조치만 알린다. 블로그 완료 상태는 영상 실패로 되돌리지 않는다.

## 글 상단 요청 안내

두 블로그 발행 자동화에는 이미 본문 맨 위에 ‘측량및지형공간정보기술사 친구 요청 문제 제출’과 https://geoai-na.netlify.app/questions/ 주소를 큰 글씨로 넣고, 둘 모두 같은 요청 페이지에 링크하도록 반영했다.

## 구현 전 확인과 검증

Voicebox 앱과 로컬 API, 지정 프로필은 확인했다. 구현 단계에서는 음성 생성·내보내기 인터페이스, 설치 모델, 개인 채널 인증 및 예약 공개 지원을 검증한다. 영상 공개 작업은 기존 사용자 요청 범위에서 수행한다. 중복 방지와 1시간 시각 계산은 실제 공개 전에 검증한다.

## 크레딧 최소화

사용자의 크레딧 최소 사용 요구에 따라 기존 블로그 답안과 그림·표를 재사용한다. 블로그 원고 작성 시 영상용 요약 대본도 함께 마련하여 별도 대본 생성 API 호출을 추가하지 않는다. Voicebox 로컬 음성과 ffmpeg 합성을 사용하고 외부 유료 영상·음성 생성 서비스는 추가하지 않는다. 아바타·AI 배경 영상·추가 쇼츠 제작은 범위에 넣지 않는다.

대본·그림·음성 프로필·생성 설정의 콘텐츠 해시를 기준으로 음성과 화면을 캐시한다. 오류 복구 시 바뀌거나 실패한 장면만 다시 처리하고 업로드 재시도 때문에 전체 영상을 다시 만들지 않는다. 구현은 이 채팅의 단일 에이전트 직접 수행을 추천한다. 검사와 예약 공개 상태 조회는 로컬 작업기로 수행하며, 빈 대기열 확인을 위해 반복적으로 모델을 호출하는 별도 영상 heartbeat를 만들지 않는다. 완료 또는 새 실패가 있는 경우에만 알린다.

유튜브 API 할당량과 이 컴퓨터의 전력·처리 시간은 별개이며, 로컬 제작을 크레딧 사용량 0인 전체 자동화라고 표현하지 않는다. 목표 시각 전에 업로드와 예약을 마치면 공개는 유튜브가 수행한다.

사용자가 설계를 확인한 후 2~3분 좌우 분할 타이핑 해설과 크레딧 최소 사용을 추가 지정했다. 영상 제작 및 자동 게시 일정은 아직 활성화되지 않았다.
