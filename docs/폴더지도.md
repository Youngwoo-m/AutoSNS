## 알아 둘 것

- **링크:** `GeoAI_NA/` 안의 `shared`, `youtube-shorts-auto`(→`channels/`), `remotion-shorts`, `geoai-site`(→`site/`), `dashboard`(=`ax-console`), `FONTS`(→`assets/FONTS`), `secrets.env.enc` 는 실제 폴더를 가리키는 링크다. 반대로 루트 `channels/naver-blog-auto/` 의 티스토리 관련 파일(`tistory_*.py`, `run_tistory.sh`, `chrome-profile-tistory`, `tistory_cookies.json`)은 `GeoAI_NA/naver-blog-auto/` 의 링크다. 루트의 `engineer-video-output` 링크는 그 안의 옛 기록 경로 때문에 남겼다. 나머지 루트 링크(`reference-posts`, `engineer-question-worker`, `civil-engineer-writing`)는 없앴으니 `GeoAI_NA/...` 로 쓴다.
- **크롬 프로필:** 각 모듈의 `chrome-profile*` 폴더에 로그인 세션이 있다. 경로는 `shared/axlock.py` 의 `PROFILES` 가 정하고, 프로필을 여는 작업은 `axlock` 을 거쳐 잠금을 잡는다(`AGENTS.md`).
- **가상환경:** 모듈마다 `.venv/` 가 따로 있다(`naver-blog-auto`, `youtube-shorts-auto`, `insta-cardnews`, `analytics`, `GeoAI_NA/claude-jobs`). 폴더를 옮기면 가상환경 안 스크립트의 절대경로가 깨진다.
- **자동 작업과 경로:** launchd 작업(`~/Library/LaunchAgents/com.smuds.*.plist`)은 이 폴더 아래 스크립트를 절대경로로 부른다. 콘솔 '자동 작업' 탭이나 `ax-console/config/automations.json` 이 전체 목록이다.
- **폴더 깊이:** `channels/*`·`site/*` 안의 코드는 저장소 루트에서 두 단계 아래다. 루트를 찾을 때 `os.path.dirname` 을 세 번(`…/channels/<모듈>/x.py` → 루트), 셸 스크립트의 `../shared` 는 `../../shared` 로 쓴다. 같은 `channels/` 안의 다른 모듈은 `../<모듈>` 그대로다.
- **산출물 위치:** 각 모듈의 `posts/`(만든 글·영상), `logs/`(실행 기록), `state`·`*_state.json`(중복 발행 방지 기록)은 git 에 올리지 않는다. 기술사 자료는 `/Volumes/USB256/기술사/`(숏츠·PDF)와 `GeoAI_NA/civil-engineer-writing/` 에 나뉘어 있다.
- **어디에 둘까:** 새 공용 코드는 `shared/`, 새 서브에이전트는 `.claude/agents/`, 한 번 쓰는 스크립트는 `tools/`, 클로드 작업은 `GeoAI_NA/claude-jobs/`, 계획·기록 문서는 `docs/`.
