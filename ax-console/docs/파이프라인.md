# AX 콘텐츠 파이프라인

콘솔의 **콘텐츠** 탭에서 콘텐츠 하나가 아래 단계를 차례로 지난다. (2026-10-18 정리)

```
① 기획 → ② AI 초안 → ③ 사람 검토 → ④ 제작 → ⑤ 채널별 예약 → ⑥ 발행 확인 → ⑦ 성과
```

| 단계 | 누가 | 하는 일 | 상태 값 | 구현 |
|---|---|---|---|---|
| ① 기획 | 사람 | 계정(학과/개인), 주제, 참고 메모, 올릴 채널을 정한다 | `idea` | 완료 |
| ② AI 초안 | AI (세명대 게이트웨이, 실패 시 Anthropic 키) | 원문 1개 + 채널별 변환본(블로그 글, 카드뉴스 문구, 숏츠 대본, X·스레드 짧은 글 등). 불확실한 사실은 `[확인 필요]` 로 표시 | `drafting` → `review` | 완료 (`app/draft_ai.py`) |
| ③ 사람 검토 | 사람 | 원문·변환본을 고치고 점검표 4개(출처, 수치·날짜, 자극적 표현, AI 고지)를 확인. `[확인 필요]` 가 남아 있으면 승인 불가 | `review` | 완료 |
| ④ 제작 | AI + 사람 | 디오라마 이미지·썸네일·Remotion 영상 | — | 다음 단계 (4단계 영상 스튜디오) |
| ⑤ 채널별 예약 | 사람 | 채널마다 발행 시각을 정하고 승인 → 채널마다 예약 작업이 생김 | `scheduled` | 완료 |
| ⑥ 발행 확인 | 사람 (자동 발행 연결 전) | 시각이 되면 작업이 '발행할 차례'(`due`)가 된다. 변환본을 올린 뒤 주소를 넣어 완료 표시. 모든 채널이 완료되면 발행됨 | `published` / `failed` | 완료 (수동 발행) |
| ⑦ 성과 | 자동 | 조회수·노출을 콘텐츠에 붙이고 다음 기획에 반영 | — | 다음 단계 (analytics 연결) |

## 지키는 것

- 사람이 승인하지 않은 글은 예약에 오르지 않는다.
- 아직 채널 자동 발행 연결이 없어서, 시각이 됐다고 '완료'로 처리하지 않는다. 사람이 실제로 올렸을 때만 완료다.
- 예약된 뒤에는 글을 고칠 수 없다. 고치려면 예약을 취소해 검토 단계로 돌린다.
- 참고 메모는 AI 에게 자료로만 넘기고 지시문으로 쓰지 않는다.

## 저장 위치

`data/content/YYYY/MM/<콘텐츠ID>/`
- `meta.json`: 상태, 점검표, 채널, 연결된 예약 작업, 기록
- `원문.md`, `변환본_<채널>.md`: 사람이 바로 열어 볼 수 있는 사본

## 기존 자동 작업과의 관계

launchd 자동 작업 25개(숏츠, 카드뉴스, 블로그 시리즈 등)는 이 파이프라인을 거치지 않고 지금처럼 돈다. **자동 작업** 탭에서 켜고 끄고 지금 실행할 수 있다. 앞으로 시리즈별로 "③ 사람 검토"를 거치게 할지는 `docs/설계.md` 의 '정해야 할 것' 4번에서 정한다.

## 다음에 할 일

1. ⑥ 채널 자동 발행 연결: 블로거(`post_blogger`), 네이버(`publish_naver`), 인스타(`post_instagram`), X(`x_post`) 같은 기존 발행 함수를 콘텐츠 작업에서 부르게 한다.
2. ④ 영상 스튜디오: 디오라마 2~3장 생성 + Remotion 렌더 (CLAUDE.md 영상 지침).
3. ⑦ 성과: `analytics` 수집 결과를 발행 주소로 콘텐츠에 붙인다.
