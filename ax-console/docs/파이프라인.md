# AX 콘텐츠 파이프라인

콘솔의 **콘텐츠** 탭에서 콘텐츠 하나가 아래 단계를 차례로 지난다. (2026-10-18 정리)

```
① 기획 → ② AI 초안 → ③ 사람 검토 → ④ 제작 → ⑤ 채널별 예약 → ⑥ 발행 확인 → ⑦ 성과
```

| 단계 | 누가 | 하는 일 | 상태 값 | 구현 |
|---|---|---|---|---|
| ① 기획 | 사람 | 계정(학과/개인), 주제, 참고 메모, 올릴 채널을 정한다 | `idea` | 완료 |
| ② AI 초안 | AI (세명대 게이트웨이, 실패 시 Anthropic 키) | 원문 1개 + 채널별 변환본(블로그 글, 카드뉴스 문구, 숏츠 대본, X·스레드 짧은 글 등). 불확실한 사실은 `[확인 필요]` 로 표시 | `drafting` → `review` | 완료 (`app/draft_ai.py`) |
| ③ 사람 검토 | 사람 | 원문·변환본을 고치고 점검표 4개(출처, 수치·날짜, 자극적 표현, AI 고지)를 확인. `[확인 필요]` 가 남아 있으면 승인 불가 | `review` | 완료 |
| ④ 제작 | AI + 사람 | 디오라마 이미지·썸네일·Remotion 영상 | — | 다음 단계 (4단계 영상 스튜디오) |
| ⑤ 채널별 예약 | 사람 | 채널마다 발행 시각을 정하고 승인 → 채널마다 예약 작업이 생김 | `scheduled` | 완료 |
| ⑥ 발행 | 자동 또는 사람 | 승인할 때 채널마다 **자동 발행** / **직접 발행**을 고른다. 자동은 정한 시각에 기존 발행 코드로 올리고 주소를 기록한다(`app/publishers.py`). 직접은 시각이 되면 '발행할 차례'가 되고, 올린 뒤 완료 표시. 자동 발행이 실패하거나 건너뛰면 실패로 남고 직접 올려 완료 표시할 수 있다 | `published` / `failed` | 완료 |
| ⑦ 성과 | 자동 | 조회수·노출을 콘텐츠에 붙이고 다음 기획에 반영 | — | 다음 단계 (analytics 연결) |

## 지키는 것

- 사람이 승인하지 않은 글은 예약에 오르지 않는다.
- 시각이 됐다고 '완료'로 처리하지 않는다. 자동 발행은 채널이 주소를 돌려줬을 때, 직접 발행은 사람이 완료 표시했을 때만 완료다.
- 예약된 뒤에는 글을 고칠 수 없다. 고치려면 예약을 취소해 검토 단계로 돌린다.
- 참고 메모는 AI 에게 자료로만 넘기고 지시문으로 쓰지 않는다.

## 자동 발행 연결 (⑥)

| 계정 · 채널 | 쓰는 코드 | 지키는 것 |
|---|---|---|
| 학과 · 블로거 (smuds2026) | Blogger API, `post_blogger` 의 인증·하루 한도 | 자동 작업(진로 시리즈·요일별 글)과 **같은 하루 한도(1편)**를 쓴다. 한도를 다 썼으면 건너뜀. 같은 제목이 있으면 건너뜀 |
| 개인 · 블로거 (geoaina) | Blogger API, `geoai_blogger` 인증 | 오늘 이미 3편 이상이면 건너뜀(GeoAI 아침·저녁 글 포함). 같은 제목이면 건너뜀 |
| 학과 · 네이버 블로그 | `publish_naver.publish` (본문 경로, 배너 없음) | 크롬 브라우저 자동화. 점검은 발행 버튼 직전에 멈춤. **점검은 5분 간격**(연달아 열면 편집기 자동저장이 다음 글에 섞임) |
| 학과 · X | `x_post` 세션으로 글만 게시 | `config x.enabled` 가 꺼져 있으면 점검만 한다. 280자 가중치 안으로 자름 |
| 인스타그램 | — | 카드 이미지가 있어야 올라가서 아직 직접 발행. ④ 제작 단계(카드 생성) 뒤 연결 |
| 그 밖(틱톡·스레드·티스토리 등) | — | 직접 발행 |

모든 자동 발행 글 끝에는 "AI 도움을 받아 초안을 만들고 사람이 검토해 올렸습니다" 한 줄을 붙인다.
승인 전에 **발행 점검** 버튼으로 각 채널을 '게시 직전'까지 돌려 볼 수 있다.

## 저장 위치

`data/content/YYYY/MM/<콘텐츠ID>/`
- `meta.json`: 상태, 점검표, 채널, 연결된 예약 작업, 기록
- `원문.md`, `변환본_<채널>.md`: 사람이 바로 열어 볼 수 있는 사본

## 기존 자동 작업과의 관계

launchd 자동 작업 25개(숏츠, 카드뉴스, 블로그 시리즈 등)는 이 파이프라인을 거치지 않고 지금처럼 돈다. **자동 작업** 탭에서 켜고 끄고 지금 실행할 수 있다. 앞으로 시리즈별로 "③ 사람 검토"를 거치게 할지는 `docs/설계.md` 의 '정해야 할 것' 4번에서 정한다.
