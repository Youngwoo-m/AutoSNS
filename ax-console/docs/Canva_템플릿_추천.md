# Canva 템플릿·크기 추천

자동 작업 25개와 콘텐츠 파이프라인에서 실제로 나오는 콘텐츠 종류를 기준으로, 만들어 둘 Canva 브랜드
템플릿과 채널별 크기를 추천한다. (2026-10-18)

---

## 2. 작업별 추천 템플릿

| # | 템플릿 | 쓰는 작업 | 크기·쪽 | 필드 | 디자인 방향 |
|---|---|---|---|---|---|
| T1 | **생활안전 수칙 카드** | 인스타 카드뉴스(`instacards.weekly`), 콘텐츠 파이프라인 학과 인스타, 재난 숏츠 교차 게시 | 1080 × 1350 · 6쪽 (표지·본문 4·마무리) | `C1~C6_TITLE`·`_BODY`, `COVER_IMAGE`, `HANDLE`, `TOPIC_BADGE` | 표지에 디오라마 이미지(대비·대응 장면) 크게, 본문은 번호 + 짧은 수칙 한 줄. 재난 종류별 색(대설 파랑, 폭염 주황, 호우 청록) |
| T2 | **채용정보 카드** | `naverjobs.weekly` 의 인스타 카드(`jobs_insta.py`, 지금은 한 장에 2건) | 1080 × 1350 · 6쪽 | 표지 `WEEK`, 쪽마다 `JOB1_*`·`JOB2_*`(회사·공고명·마감·지역) | 표 형식, 마감일을 가장 크게. 소방 공고는 싣지 않음(기존 규칙) |
| T3 | **진로·자격증 시리즈 표지** | `blogcareer.daily`(블로거), `ytcareer.weekly` 진로 숏츠 | 1200 × 630 + 1080 × 1920 (같은 디자인 두 크기) | `SERIES`(진로/자격증/입시), `EPISODE`(3/8), `TITLE`, `SUBTITLE` | 시리즈마다 고정 색, 회차 번호 크게. 학과 이름 아래 |
| T4 | **O/X 퀴즈 카드** | 진로·퀴즈 숏츠 표지, 인스타·스레드 퀴즈 | 1080 × 1350 · 2쪽(문제·정답) / 1080 × 1920 표지 | `QUESTION`, `ANSWER`(O/X), `EXPLAIN`, `NUMBER` | 큰 O·X 기호, 정답 쪽은 색 반전 |
| T5 | **요일별 블로그 대표 이미지** | `naverblog.weekly`(월~일 에디션), 블로거 같은 글 | 1080 × 1080 + 1200 × 630 | `EDITION`(재난안전판 등), `TITLE`, `DATE` | 에디션마다 배지 색. 지금 쓰는 '재난안전 브리핑' 배너를 대체 |
| T6 | **재난 속보 표지** | `ytshorts.trigger`(사건 즉시 숏츠) | 1080 × 1920 | `EVENT`(대설특보 등), `REGION`, `ACTION`(지금 할 일) | 자극적인 사고 장면 대신 '지금 할 일' 중심. 붉은색은 배지에만 |
| T7 | **GeoAI 개념 카드·대표** | `geoai.daily`·`geoai.evening`(개인 블로거), `tistory` | 1200 × 630 + 1080 × 1350 · 4쪽 | `TITLE`, `CONCEPT`, `C1~C4_*`, `DIAGRAM_IMAGE` | 개인 계정 색(보라 계열). 개념도·흐름도 이미지 칸 |

**우선순위**: T1(가장 자주, 인스타 자동 발행에 바로 필요) → T5(매일 블로그 2곳) → T3 → T7 → 나머지.

## 3. 모든 템플릿 공통 규칙

- 글꼴: 제목·숫자·배지 **Pretendard Bold**, 인스타 카드 본문 **KoPub 돋움 Bold** (CLAUDE.md, `FONTS/` 를 Canva 브랜드 키트에 올린다). 굵기 대신 크기·색으로 위계.
- 이미지 칸 안의 그림에는 글자를 넣지 않는다(AI 그림 속 한글은 깨진다). 글자는 모두 텍스트 필드로.
- 디오라마 이미지: 아이소메트릭 미니어처 질감, 사고 순간·부상자 대신 대비·대응·구조 장면.
- AI가 만든 사람·목소리가 나오는 콘텐츠의 표지에는 `AI_NOTICE` 필드(예: "AI 합성 이미지 포함")를 둔다.
- 학과 템플릿과 개인 템플릿은 색·로고를 다르게 하고, 모든 쪽에 `HANDLE`.
- 필드 이름은 영문 대문자·숫자·밑줄(Canva 데이터 자동 입력 앱에서 상자마다 붙임).

## 4. 콘솔 설정 구조 (템플릿 여러 개)

`config/canva.json` 의 `templates` 를 계정 하나당 하나에서 **종류별**로 바꾼다.

```json
"templates": {
  "T1_safety_cards":   {"id": "", "accounts": ["dept"],     "size": [1080, 1350], "pages": 6},
  "T5_blog_cover":     {"id": "", "accounts": ["dept"],     "size": [1080, 1080], "resize_to": [[1200, 630]]},
  "T7_geoai_cards":    {"id": "", "accounts": ["personal"], "size": [1080, 1350], "pages": 4}
}
```

콘텐츠마다 어떤 템플릿을 쓸지는 **채널 + 콘텐츠 종류**로 고른다(예: 학과 인스타 + 생활안전 → T1, 학과 인스타 + 채용 → T2). 기획 에이전트가 기획 단계에서 종류를 붙인다.
