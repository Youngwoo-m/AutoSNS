# AX 발행 콘솔

학과·개인 계정의 글쓰기, 영상 제작, 업로드, 예약 발행을 한 화면에서 다루는 로컬 콘솔.

| 폴더 | 내용 | git |
|---|---|---|
| `docs/` | 설계 문서 (`설계.md`) | 올림 |
| `design/` | 화면 시안 HTML | 올림 |
| `app/` | 콘솔 코드. 지금은 대시보드 생성기 `build_dashboard.py` 하나 | 올림 |
| `data/dashboard/` | 생성된 대시보드 `index.html` (발행할 때마다 다시 만들어짐) | 제외 |
| `data/content/` | 콘텐츠 원문·매체별 변환본 (`YYYY/MM/<콘텐츠ID>/`) | 제외 |
| `data/media/` | 디오라마 이미지·썸네일·렌더된 영상 (`YYYY/MM/<콘텐츠ID>/`) | 제외 |
| `data/runs/` | 발행 실행 기록·로그 (`YYYY-MM-DD.jsonl`) | 제외 |
| `data/analytics/` | 매체별 성과 수집 결과 | 제외 |

`data/` 는 실행할 때 생기는 산출물이라 git 에 올리지 않는다. 백업은 `backup_state.sh` 대상에 넣는다.

## 실행

```
python3 ax-console/app/server.py      # http://127.0.0.1:8700
```

- **계정 연결** (첫 화면): 학과·개인 구글 토큰(유튜브·블로거·서치콘솔) 상태와 실제 연결된 채널·블로그, 로그인 버튼(기존 인증 스크립트 실행). 네이버(학과·개인)·카카오(개인)·Netlify 상태, GitHub 계정 3개(모두 개인 구글) 기본 계정 전환
- **자동 작업**: launchd 작업 25개를 계정별·채널별로 (분석: `config/automations.json`, `docs/자동작업_목록.md`)
- **콘텐츠**: 파이프라인 보드(① 기획 ~ ⑥ 발행). 세명대 게이트웨이로 원문·채널별 변환본 초안, 점검표 승인 후 채널별 예약
- **작업**: 학과/개인 → 채널을 고르고 수행 내용 입력·수정, 실행 작업 선택, 예약 걸기, 지금 실행, 실행 기록 보기
- **예약 목록**: 콘솔 예약과 launchd 자동 작업을 앞으로 8일치 시간순으로 (계정·채널·출처로 거르기)
- **설정**: 계정 정보 수정, 비밀값 저장 여부, 세명대 AI 게이트웨이(모듈별 설정·사용량·키 확인), 플러그인 켜기/끄기, 커넥터, 설치된 스킬
- 서버는 launchd `com.smuds.axconsole` 로 로그인할 때 켜지고, 꺼지면 30초 안에 다시 켜진다.
  다시 시작: `launchctl kickstart -k gui/$(id -u)/com.smuds.axconsole` · 로그: `data/logs/server.*.log`
- 예약은 서버가 켜져 있을 때만 실행된다(USB가 빠져 있으면 서버도 못 켠다). `data/tasks.json` 에 작업, `data/runs/` 에 실행 기록이 쌓인다.

## 진행 상황 (2026-10-18)

설계 문서(`docs/설계.md`)의 단계 기준.

| 단계 | 상태 |
|---|---|
| 0 계정 연결 | 완료 — 구글 토큰 확인·재로그인, 네이버·카카오·Netlify 표시, GitHub 전환 |
| 1 읽기 전용 콘솔 | 완료 — 자동 작업·예약 목록·대시보드 |
| 2 예약 관리 | 완료 — 콘솔 자체 예약(입력·수정·예약·지금 실행·기록), 자동 작업 탭의 launchd 켜기/끄기(bootout·disable / enable·bootstrap)·지금 실행(kickstart, 발행 작업은 "실제로 발행됩니다" 확인)·최근 로그 보기. 제어 대상은 config/automations.json 의 작업만, 콘솔 자신(axconsole)은 끌 수 없음. 일부러 끈 작업(note·reenable)은 켤 때 사유를 다시 보여 준다. 제어 기록은 data/logs/launchd_control.log |
| 3 작성 스튜디오·승인함 | 완료 — 콘텐츠 탭: 기획 → AI 초안 → 검토·점검표 → 채널별 예약 → 발행 확인 (`docs/파이프라인.md`). 채널별 자동 발행: 블로거(학과·개인)·네이버(학과)·X(학과). 인스타는 카드 이미지가 필요해 직접 발행 |
| 4 영상 스튜디오 | 아직 |
| 5 성과 | 아직 (analytics 보고서는 기존대로 돈다) |

남은 확인 사항: 개인 네이버 계정 연결, surveymadang 의 `gh auth login`, 평문 키가 남은 config 백업 8개 정리.
